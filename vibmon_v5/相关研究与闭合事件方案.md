# 相关研究与闭合事件方案

> **记录日期**：2026-10-30
> **状态**：参考资料与实验方案记录，诊断功能已实现
> **边界**：闭合事件和 `touchScore` 只作为诊断/研究，不改变当前 `contact` 判据

---

## 1. 结论

外部资料支持当前的判断方向，但没有证明“仅靠 MPU6050、无振动、无机械限位”可以稳定判断静态夹物：

- 指尖 IMU 的常见用法是检测**接触事件、滑移、冲击和振动传导**；
- 静态抓握力或无振动接触通常需要压力、应变、力或主动振动等互补信号；
- 因此 v5 继续保留 `θ 判闭合 + A/F 判接触`，不把静态 Y/Z 加权直接接入 `contact`；
- 下一步更值得做的是**闭合事件窗口**，而不是继续调静态权重。

这条路线与当前 v5 的四格结果一致：C6 有明显 A/F 证据时可靠；C5 压住静止物体时没有足够证据，不能硬猜。

## 4. 闭合事件状态机草案

目标是把一次“手指合上”的动作切成可重复的事件，避免把开合过渡混进稳态特征。

| 状态 | 进入条件（草案） | 主要动作 |
|---|---|---|
| `ARMED` | 角度接近 0，角速度在死区，且最近未提交事件 | 清空本次事件缓存，等待闭合 |
| `MOVING` | 角度开始增长或 `gyroW` 超过动作门限 | 记录起点，开始累计陀螺能量和事件统计 |
| `PLATEAU` | `MOVING` 后连续 200~300 ms 角速度在死区 | 记录候选停止点和过渡段特征 |
| `COMMIT` | `PLATEAU` 再持续 300~500 ms，未重新启动 | 冻结本次事件特征，递增 `eventId` |
| `OPEN` | 回到张开位并静止满 500 ms | 结束本次事件，回到 `ARMED` |

### 4.1 关键约束

- `PLATEAU` 不要求角度一定大于 60°。夹物时可能在较小角度提前停住，若过早要求“已闭合”，会错过有用事件。
- `COMMIT` 后不再更新本次事件的终值特征，避免手抖和等待时间改变分类结果。
- 回到张开位才算一次事件完整结束；若长时间不张开，保持 `COMMIT` 并标记超时。
- 一次闭合若出现多次短暂停顿，用“重新超过动作门限则回到 `MOVING`”处理，避免把中途抖动提交成事件。
- 事件状态机只做诊断，不直接改写 `contact`。

建议先按以下参数做实验，不先固化进 `config.h`：

```text
事件启动角        10 deg
动作角速度门限    3 dps
PLATEAU 初判      250 ms
COMMIT 确认       300 ms
回张开确认        500 ms
稳态均值窗口      500 ms
```

这些值需要用实际闭合曲线和日志重新确定，不能当作已验证参数。

## 5. 事件特征

定义：

- `t0`：`MOVING` 起点；
- `tPlat`：`PLATEAU` 起点；
- `tCommit`：`COMMIT` 时刻。

| 特征 | 定义 | 物理意义 | 注意 |
|---|---|---|---|
| `openToCloseMs` | `tPlat - t0` | 从开始闭合到停住的时间 | 受操作速度影响，需同人同动作比较 |
| `plateauAngle` | `COMMIT` 前 100~200 ms 的角度均值 | 被物体挡住时的停止角 | 仍受装贴位置影响 |
| `gyroPeak` | `[t0,tPlat]` 内最大 `gyroW` | 闭合峰值角速度 | 快速闭合时可能超量程 |
| `gyroEnergy` | `[t0,tPlat]` 内 `sum(gyroW^2 * dt)` | 转动过程能量 | 对采样中断敏感 |
| `impactA` | `[tPlat-50ms,tPlat]` 内最大幅值 | 停止前的机械冲击 | 需要 `ampValid` |
| `ringdown` | `tPlat` 后 100 ms 能量 / 停止前能量 | 停止后的振动衰减 | 无振动时无定义，不能硬填 0 |
| `decayTau` | 停止后包络指数拟合时间常数 | 冲击衰减速度 | 样本不足时不输出 |
| `ctYMean` | `[tCommit,tCommit+500ms]` 的 Y 均值 | 停止位姿的横向投影 | 跨摆放位置敏感 |
| `ctZMean` | 同窗口 Z 均值 | 停止位姿的另一投影 | 与 Y 不独立 |
| `angleSlope` | `tPlat` 前 100 ms 的角度斜率 | 到达停止点前的减速程度 | 需先做平滑 |

`ringdown`、`impactA` 和 `decayTau` 在振源关闭时可能无效；此时输出 `?` 或 `scoreValid=false`，不要填 0 后参与分类。

## 6. 数据输出草案

现有 CSV 是 `seq,t_ms,ctX,ctY,ctZ,ctDev,ampMg,vib,contact,cvalid,gap,label,ctTouchDist,closed,ang,gyroW`，
不要直接打乱现有列顺序，避免旧脚本失效。

建议新增独立的 `EV` 汇总行，或在新版本里追加列：

```text
EV,eventId,phase,closureMs,plateauAngle,gyroPeak,gyroEnergy,
impactA,ringdown,decayTau,ctYMean,ctZMean,angleSlope,touchScore,scoreValid
```

若在固件中实现，建议同时输出：

| 字段 | 用途 |
|---|---|
| `phase` | 离线复核事件切分是否正确 |
| `eventId` | 防止同一动作被重复计数 |
| `closureMs` | 比较闭合速度 |
| `plateauAngle` | 与现有 `ang` 对照 |
| `touchScore` | 仅诊断，不参与 `contact` |
| `scoreValid` | 避免把“没有足够数据”当成低分 |

## 7. 离线验证方案

### 7.1 数据采集

先做振源关闭的静态物体实验，避免 A/F 直接帮助分类：

- 类别：空握、4 cm 方块、5 cm 方块；
- 每个类别至少 10 次独立闭合事件；
- 至少 3 个摆放位置；
- 每个位置重新张开、停顿、闭合，不复用同一段连续数据；
- 每组另做一次振源开启数据，只用于检查事件特征是否被振动污染。

### 7.2 统计方法

1. 先画单次事件的 `ang(t)`、`gyroW(t)`、`ampMg(t)`；
2. 检查 `PLATEAU` 是否落在真正的停止段，而不是手抖或过渡；
3. 对单特征计算组间差、组内标准差和 AUC；
4. 用 LDA、逻辑回归或小决策树做离线分类；
5. 按“事件”分组划分训练/测试，不能把同一事件的相邻帧拆到两边；
6. 最好采用留一摆放位置验证，检查是否只对某一个位置过拟合。

### 7.3 接入正式判据的门槛

至少同时满足：

- 类间分离达到组内标准差的约 3 倍；
- 留一位置验证没有系统性误判；
- 关闭振源时仍能重复，不依赖偶然的 A/F；
- 机械限位前后结论一致，或限位后确实改善。

未达到时，`touchScore` 只能显示，不能改变 `contact`。

## 8. 机械方案的两个分支

### 8.1 张开止位（优先）

让每次松手后的起始姿态一致，主要改善角度零位和 Y/Z 的重复性。它不直接制造“空握 vs 夹物”的角度差。

### 8.2 闭合机械止位（实验分支）

也可以尝试在“空握最终位置”附近加一个可调硬止位：

- 空握时手指停在固定止位；
- 夹物时物体先挡住手指，使手指停在止位之前；
- 理论上可把“有没有物体”转成更稳定的角度差。

但不能直接采用，必须先验证：

1. 止位不会妨碍对物体施加正常夹持力；
2. 物体不会因为止位被挤坏；
3. 空握和夹物的停止顺序确实相反；
4. 柔性板、指甲盖模块和走线不会被止位挤压。

这是一项机械结构实验，不是当前固件可以单独解决的问题。

### 9.3 用回落轨迹做复位：方向对，但不能在“刚进入缓降”时归零

观察到的典型回落形状确实是：

```text
峰值 -> 快速下降 -> 进入缓降 -> 接近静止 -> 下一次闭合
```

但不能把“刚到缓降位置”直接当作复位点，因为当前实测的缓降入口和最低点并不固定：

| 组 | 回落最低角 | 进入缓降时的角（粗测） |
|---|---:|---:|
| 空握 | 多次约 0.0~0.5°，个别 20.3° | 0~24° |
| 4 cm | 约 5.9~26.5° | 约 18~34°，个别受抖动影响 |

如果一进入缓降就把角度清零，零点会随每次动作漂移，下一次闭合角也会被改变。
更稳妥的做法是把回落分成三个阶段：

```text
RETURN_FAST   : 角度快速下降
RETURN_SLOW   : 下降速度明显减小
RETURN_STABLE : |角度斜率| < 2~3 deg/s 且角度极差 < 2~3 deg，持续 300~500 ms
```

只有 `RETURN_STABLE` 才设置本轮的 `cycleZeroAngle`，然后重新 `ARMED`。
输出时同时保留：

- `settleAngle`：稳定后的角度；
- `settleSlope`：稳定窗口内角度斜率；
- `settleStableMs`：满足稳定条件的时间；
- `closureAngleRelative = plateauAngle - cycleZeroAngle`。

这样即使机械手不能回到物理 0°，也可以用“本轮稳定回落点”作为相对零点；
但它不能和不同类别/不同位置的绝对角度直接混用。

验收条件：同一状态连续 10 次，缓降入口角的极差应小于约 3~5°，
稳定点角度极差也应小于约 3~5°；否则只能把回落轨迹当辅助特征，不能直接改固件零点。

### 9.4 回落检测已加入离线脚本

`event_analyze.py` 现已输出：

- `releaseFastMs`：从 plateau 到检测到快速下降的时间；
- `releaseSlowMs` / `releaseSlowAngle`：进入缓降的时间与角度；
- `releaseStableMs`：满足稳定窗口的时间；
- `returnMinAngle` / `returnMinMs`：回落最低点和时间；
- `settleAngle` / `settleSlopeDegS`：稳定窗口均值和斜率；
- `cycleZeroAngle`：只有 `releaseStable=1` 时才输出的本轮相对零点；
- `closureAngleRelative`：`plateauAngle - cycleZeroAngle`。

当前参数：快速下降门限 `20 dps`，缓降门限 `5 dps`，稳定斜率 `2.5 dps`，
稳定角度极差 `2.5°`，稳定窗口 `500 ms`。这些仍是实验参数。

实测：

- 4 cm p1 的 8 个事件全部检测到稳定回落，缓降入口约 16.5~28°，
  稳定点约 7.0~24.4°，相对闭合角约 91.9~108.8°；
- 空握 p1 只有部分事件能计算稳定回落，部分事件在释放段存在约 2 s 的数据缺口，
  不能伪造缺失段，直接标记为 `releaseStable=0`。

结论：回落检测已经可用，但“缓降入口”和“稳定点”的跨周期极差仍然偏大，
暂时只能作为离线相对零点和诊断特征，不能直接替代固件的绝对归零。

### 9.5 回落重复性统计

按当前参数统计已有事件：

| 组 | 事件数 | `releaseStable=1` | 缓降入口范围 | 稳定点范围 | 相对闭合角范围 |
|---|---:|---:|---:|---:|---:|
| 空握 p1 | 7 | 2 | 0.9~23.9° | 11.4~22.1° | 86.9~90.0° |
| 4 cm p1 | 11 | 10 | 16.5~31.9° | 7.0~29.9° | 91.9~108.8° |
| 5 cm p1 | 10 | 10 | 14.2~31.6° | 12.1~29.9° | 80.5~105.3° |

结论：

- 4 cm 的缓降入口和稳定点范围仍远大于 3~5°，不满足固定零点条件；
- 5 cm 的 10 个有效事件全部有稳定回落，但相对闭合角极差约 24.8°，
  仍不能满足固定零点条件；
- 空握多数事件因释放段有约 2 s 数据缺口，无法计算稳定回落，不能把缺失段当成 0。

因此当前最合理的用途是：

1. 保留 `releaseStable` 作为数据质量门；
2. 用 `cycleZeroAngle` 做同一轮内的相对角；
3. 暂不改固件的绝对角度复位；
4. 先解决采集缺口或机械回位重复性，再重新做 10 次以上统计。

### 9.6 START / FINISH / HONGEST 的机械定义

按用户图示：

| 标记 | 机械含义 |
|---|---|
| `START` | 初始张开位置 |
| `FINISH` | 握紧之后的缓降/回位位置 |
| `HONGEST` | 空握位置 |

图上的机械位置分离明显，但当前 `closeAngleDeg` 是“三轴积分后取绝对值最大”的
标量，丢失了方向和轴信息；因此机械上可分的三个位置，在标量角上可能重叠。

下一步应使用：

- `ctXMean / ctYMean / ctZMean`：平台段的三轴姿态向量；
- 后续若改固件，再输出 `angleX/Y/Z` 与 `gyroX/Y/Z`；
- 在二维机械平面或三维姿态空间里计算 `START / FINISH / HONGEST` 的类间距离。

### 9.9 FINISH 的语义修正

继续采集后确认：`FINISH` 不是静态姿态，而是“握紧之后的缓降/回位阶段”。
在 `static_cycle_3.csv` 中，FINISH 段的三轴向量会从大约
`(260, 3, 142) mg` 连续滑到 `(80, -4, 34) mg`，不是固定中心。

因此：

- `START` 和 `HONGEST` 可以作为静态位置，用三轴向量分类；
- `FINISH` 应使用回落阶段特征（`releaseFastMs / releaseSlowMs / settleAngle /
  cycleZeroAngle`），不能当作第三个静态中心；
- 若一定要把 FINISH 当位置，只能定义成缓降稳定后的“回位终点”，
  该点可能与 START 很接近，不能再用静态距离硬分。

### 9.10 跨采集绝对向量漂移

| `static_cycle_3` | (105.1, -4.2, 45.0) | (654.1, 63.9, 780.8) | (-377.2, 98.6, 1976.8) |

以 START 为基准的相对向量也明显不同：

| 采集 | FINISH - START | HONGEST - START |
|---|---|---|
| `static_cycle_2` | (196.7, 1.3, 81.2) | (501.0, 34.6, 1626.3) |
| `static_cycle_3` | (549.0, 68.2, 735.8) | (-482.3, 102.8, 1931.7) |

### 9.21 `stableCls` 防抖验证

`posture_transition_9.csv`：

|---|---|---|---:|---:|

## 10. 不采用的方案

- 不用手拍权重的 `0.4*Y + 0.3*Z + ...` 直接接入 `contact`；
- 不在过渡段上计算稳态 Y/Z；
- 不用单次动作或单帧分类结果替代统计验收；
- 不为静态触摸牺牲当前已通过的 80~180 Hz 振动检测；
- 不在比赛固件中引入数据量和部署成本都不合适的神经网络。
