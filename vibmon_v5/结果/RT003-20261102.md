## 数据结论（结论是什么）

1. **2021~2026 六届中，没有任何一届出现过"检测无振动状态下的接触"（静态夹物判接触）要求**，无逐届例外。
2. 历届传感器检测类赛项只有两届：2025（电参数检测）与 2026（振动检测）；其余均为机器人/3D 打印类。2026 的接触检测在命题里明确与「持续振动或周期振动」绑定，接触对象始终是带可控振动激励的测试件。
3. 「静止无振动接触」既非历届要求，也与本届命题原文不符——该场景不构成命题缺口，属物理判据上限（与既有调研结论一致，现有了历届证据支撑）。
4. **开源代码佐证（2026-11-02 ego-browser 二轮补充）**：同赛项其他队伍公开仓库 `zhangxianggan/zongjisa-mpu6050`（ESP32-C3+MPU6050，ESP-IDF）的判据为「频带内 RMS 门限 + 过零频率」二重与（`main.c:178-180`: `in_vibration_band && strongest_rms >= rms_threshold`），**完全没有接触/静态夹物判定**；其串口帧字段 `vibration,carrier_hz,start_stop_hz,rms_g` 与我方 $VD 帧的 VIB/F/SS/AMP 字段一一对应，印证"接触状态输出"是我方相对同赛项其他队的独有增量。已存档其 main.c 与 README 至 `历届命题调研_20261102\2026同赛项他人代码_*.txt/.md`。
