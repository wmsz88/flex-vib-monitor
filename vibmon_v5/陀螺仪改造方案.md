# 陀螺仪改造方案与实测记录

> **日期**：2026-10-29　**状态**：待评审　**目标**：用陀螺仪积分角度判"夹没夹住"，替代现在不可用的 `D`
> **依据**：`进度.md` §8.7 与 §8.8 两次实测——`D` 对"夹空气 vs 夹 4cm 物体"只有 5~10% 差异，
> 与机械手回位不一致（实测 122~1382mg）同量级，**不可作为判据**。

---

## 1. 为什么要改

| 观测量 | 物理含义 | 缺点 |
|---|---|---|
| `D`（现有） | 重力方向相对基准转过的角度，**投影到重力平面** | 转动轴接近平行重力时几乎不变；实测只有 5~10% 分辨力 |
| 陀螺积分角度 θ | 实际转过的角度，**与重力方向无关** | 有零偏漂移，必须做零速修正 |

`D` 的分辨力问题不是调参能解决的：夹住 4cm 物体只让手指少转几十度，
这点角度在重力投影上就是百分之几，而机械手每次张开的位置差异比它更大。

**陀螺仪积分得到的是角度本身**，1° 量级即可分辨，正好是"收缩程度"这个物理量。

## 2. 硬件与寄存器事实（已核对数据手册与现有代码）

| 项 | 值 | 出处 |
|---|---|---|
| 陀螺寄存器 | `0x43~0x48`（X/Y/Z，各 16bit 大端） | MPU6050 寄存器表 |
| 温度寄存器 | `0x41~0x42` | 同上 |
| 连读起点 | `0x3B` 起 **14 字节** = 加速度6 + 温度2 + 陀螺6 | 现有 `REG_ACCEL_XOUT_H=0x3B` |
| `GYRO_CONFIG` | 现有写 `0x00` ⇒ **±250 dps**，131 LSB/(°/s) | `mpu.cpp` |
| 建议量程 | `0x08` ⇒ **±500 dps**，65.5 LSB/(°/s) | 手指快速闭合可到 300~400 dps |
| `DLPF_CFG` | 现有 `0` ⇒ 加速度 260Hz / 陀螺 256Hz | 够用，不必改 |
| `SMPLRT_DIV` | `0` ⇒ 1kHz | 不必改 |
| I2C 时钟 | 200kHz | `I2C_CLOCK` |

**实测 I2C 耗时**（`selftest` 第 12 项）：6 字节约 **420µs**，折合 ≈70µs/字节。

- 14 字节 ≈ **980µs** —— **1kHz 周期（1000µs）装不下**，必须降频或提总线。

---

## 3. 采样带宽：三个方案

| 方案 | 做法 | 每周期 I2C 占用 | 风险 | 结论 |
|:--:|---|---|---|---|
| **A（推荐）** | 加速度保持 1kHz（6B）；陀螺 **250Hz**（每 4 个 tick 读一次 14B） | 普通 tick 420µs；陀螺 tick 980µs（4ms 周期内 25%） | 积分步长 4ms | 最稳，先做这个 |
| B | 加速度 1kHz + 陀螺 500Hz（隔 tick 读 14B） | 陀螺 tick 980µs / 2ms = 49% | 与采样抖动叠加，边界紧 | 可作二期 |
| C | I2C 提到 400kHz，14B ≈ 490µs，全程 1kHz | 49% | 5.1k 上拉 + 30cm 杜邦 + 跨弯曲区，总线电容可能超标 | 需先实测误码率 |

**方案 A 的积分精度够不够**：闭合动作历时 300~500ms，4ms 步长可采 75~125 点；
角度误差 ≈ Σ(ω·Δt) 的量化误差，按 200dps 峰值估 ≈ 0.4°，远小于要分辨的几十度。

## 4. 数据结构与接口变更

```c
/* mpu.h */
struct MpuRaw { int16_t ax, ay, az, gx, gy, gz; };   // 新增 gx/gy/gz
bool mpuReadAll(MpuRaw* out);                        // 新增：一次读 14 字节
bool mpuReadAccel(MpuRaw* out);                      // 保留：6 字节快路径

/* sampler.h */
struct Sample {
  uint32_t seq; uint32_t tUs;
  int16_t ax, ay, az;
  int16_t gx, gy, gz;      // 新增；非陀螺 tick 时 valid=false
  bool    gyroValid;       // 新增
};

/* dsp.h */
struct DspFrame {
  ...
  float gyroDps[3];        // 新增：去零偏后的角速度
  float closeAngleDeg;     // 新增：从"张开零位"起积分的闭合角度（取三轴绝对值最大者）
  bool  angleValid;        // 新增
  bool  gyroClipped;       // 新增：角速度超量程
};

/* state.h */
struct Result {
  ...
  float closeAngleDeg;     // 新增
  bool  angleValid;        // 新增
};
```

**为什么放 `Sample` 而不是另开缓冲**：陀螺与加速度必须共用同一条时间轴，
分开缓冲会让"第 N 个样本对应哪个角速度"对不上，积分会错位。

## 5. 角度估计算法

### 5.1 零偏标定（复用现有标定阶段 A）

`dspCalibrate()` 已经要求静置 2s（`CAL_BIAS_MS`），在这段里顺带累加陀螺三轴均值
⇒ `cal.gyroBias[3]`。**不额外增加标定时间。**

标定质量检查：三轴角速度标准差 > `GYRO_CAL_MAX_STD_DPS`（建议 3 dps）判为"标定时在动"，
与现有 `CAL_MAX_STD_MG` 同性质。

### 5.2 零速修正（ZUPT）—— 防漂移的关键

```c
w = |ω - bias|;                      // 三轴合成角速度
if (w < GYRO_DEADBAND_DPS) {         // 建议 1.5 dps
    stillMs += dt;
    if (stillMs > 300) { /* 冻结角度，不累加 */ }
} else {
    stillMs = 0;
    θ += (ω - bias) * dt;
}
```

**不做的后果**：MPU6050 零偏典型 ±20 dps，即使标定后残留 0.5 dps，
3 分钟也漂 90°，判据直接失效。

### 5.3 零位（θ=0 的定义）

陀螺仪测不到"绝对角度"，只测变化。所以需要一个"这里算 0°"的参照：

**用加速度计的 `D` 判"张开"，用陀螺积分测"从张开转了多少"。**

```c
if (D < OPEN_D_MG) {   // 建议 120mg：实测张开态 D=3~212，闭合态 >1500
    θ = 0;             // 判定回到张开位，清零
}
```

这样：`D` 的**绝对性**（不漂）负责"认零"，陀螺的**分辨率**（不受朝向影响）负责"量多少度"。
两者互补，正好绕开各自缺点。

### 5.4 饱和与异常

- `|ω| > 0.9 × 500dps` ⇒ `gyroClipped=true`，该段角度标记不可信（与加速度削顶同一套处理）。
- 积分结果超 `±360°` ⇒ 判异常，复位 θ 并置无效。

## 6. 三态判据设计（用 θ 替代 D）

实测预期（待验证）：夹空气闭合角 > 夹 4cm 物体的闭合角，因为物体挡住手指。

| 状态 | 判据 | 说明 |
|---|---|---|
| **松手** | `θ < θ_open`（如 20°） | 且 `D` 小，双条件防误判 |
| **握紧无物** | `θ > θ_air_on`（如 140°） | 闭合到底 |
| **接触（夹物）** | `θ_open < θ < θ_obj_off`（如 20°~110°） | 被物体挡住，闭合不完全 |

- 三档之间留滞回（各 ±10°），避免边界抖动。
- 与振动轴（`A`/`F`）仍然独立：θ 判"夹没夹住"，`A`/`F` 判"有没有振动"。
- **好处**：夹住静止物体时也能报接触（θ 落在物体档），**解决现在 C5b 漏报的问题**。

> 三档的具体角度必须实测填，不能拍脑袋。方案只定"用角度分档"这个结构。

## 7. 标定流程变更

| 步骤 | 现在 | 改造后 |
|---|---|---|
| 上电自动标定 3.2s | 加速度零偏 + 噪声 | 加：陀螺零偏 + 静止标准差 |
| `t` 采基准 | 记录 `flatRef`（三轴低通值） | 不变（仍用于 `D`，作为零位判据） |
| `c` 重标定 | 清 `flatRef` | 不变，另清 θ |
| `S` 输出 | — | 增加 `θ=xxx°(有效/无效) gyroBias=x/y/z` |

## 8. 兼容性与回退

- 新增字段**不删旧字段**，`CT_MODE` 增加 `4`（角度判据）；`CT_MODE=3` 原样保留可回退。
- `#if CT_MODE == 4` 包裹新判据，其余模式编译时自动裁掉，flash 不会明显变大。
- 若陀螺数据不可用（`gyroValid=false` 连续 >1s）⇒ 自动降级回 `CT_MODE=3` 的 `D` 判据，
  并在调试口打印 `[CT] 陀螺失效，降级 D 判据`。

## 12. 实板 H1 / H2 结果（2026-10-29）

### 12.1 H1 刻度校准：通过

把模块慢慢转过一个角度，同时读陀螺积分 `ang` 与加速度 `D`，
用 `θ_true = 2·asin(D/2000)` 独立反推真实转角：

| `D` (mg) | 加速度反推 | 陀螺积分 | 差 |
|---:|---:|---:|---:|
| 1278 | 79.5° | 79° | 0.5° |
| 1377 | 87.0° | 83° | 4° |
| 1398 | 88.8° | 87° | 2° |
| 1654 | 111.7° | 113° | 1° |
| 1769 | 124.3° | 118° | 6° |

80~125° 全程 **±6°** 内一致。刻度不需要额外校正系数。

> 期间修掉一个关键缺陷：原来只要 `D < 120mg` 就把角度清零，导致**转动起步阶段
> （D 还没超门槛）那几度被反复丢弃**，实测少积 18%（72° vs 88°）。
> 改成"**停在张开位**才清零"（`D` 小 **且** 角速度在死区）后，主机上 100.0° vs 期望 100.0°。

### 12.2 H2 夹空气 vs 夹 4cm 方块：**不通过（Go/No-Go 失败）**

| 段 | 动作 | `ang` |
|:--:|---|---:|
| A | 夹空气 | 111°（稳定段） |
| B | 夹 4cm 方块 | **100°** |
| C | 夹空气 | 106° |

**两组只差 6~11°，远低于 30° 门槛。**

原因：模块贴在**指甲**上，指甲朝向主要由近端指关节决定；方块挡住指尖后，
远端关节会多转一些来补偿，**指甲最终朝向几乎不变**。
这与 `D` 的结果（差 5~10%）互相印证：**姿态类观测量在这个装贴位置上"感觉不到"指间有没有东西。**

### 12.3 最终判据结构（据此确定）

| 要分的 | 观测量 | 实测依据 |
|---|---|---|
| **松手 vs 非松手** | `θ` 闭合角 | 0° vs 100~111°，段内极差 1°，且**与摆放位置无关**（优于 `D`） |
| **夹空 vs 夹物** | `A` / `F` 振动传导 | 6.4mg / 无效 vs 755mg / 178Hz（118 倍） |
| 夹空 vs 夹物（物体不振） | **无解** | 物理上限，两条姿态轴都试过了 |

即 §4.2 的 **M2：两轴独立输出**。`CT_MODE=4` 内部就是按这个结构写的：
`θ` 三档判"松手 / 已闭合"，振动轴单独报，不再要求"角度单独分出空夹"。

### 12.4 下一步

1. 按 §12.3 改判据：`ANGLE_OPEN_DEG` 用 20°、`ANGLE_AIR_ON_DEG` **要改成"是否闭合"的单门限**
   （因为空夹与夹物角度接近，二档门限才是稳定的）。
2. 实测填 `A`/`F` 门限：空夹 6.4mg、真接触 755mg ⇒ `CT_FLAT_A_ON` 取 50~100mg 都安全。
3. 重跑 C1/C3/C4/C6 四格，确认三态全对。

## 13. 待验证思路：用"手指位移/轨迹"区分夹空与夹物

> 来源：2026-10-29 你的提议。先记录，暂不实现。

观察：空手闭合时手指的移动路径是固定的；握 4cm 方块时手指被撑开、轨迹产生偏移。

| # | 做法 | 需要什么 | 代价 |
|:--:|---|---|---|
| T1 | 用现有 θ 的**轨迹形状**：记录闭合过程的角度-时间曲线，看是否提前停住 | 只需现在的陀螺 | 低 |
| T2 | θ 的**终值 + 到达时间**二维特征 | 同上 | 低 |
| T3 | 细分位移：250Hz 提到 500Hz，检测中途停顿/拐点 | 需要更细采样 | 中 |

为什么值得试：H2 里夹空 111/106、夹方块 100，终值只差 6~11；
但**轨迹形状**可能差很多——夹方块时手指会在接触瞬间提前减速或停住，夹空会一路转到底。

判据草案：闭合过程中若角度停在某值超过 200ms 不再增长 ⇒ 被物体挡住 ⇒ 夹物。

**验证方法**：把 data/H2.csv 的 ang 时间序列画出来看斜率与停顿，不需要新硬件。

## 17. 三轴姿态向量（坐标位移思路）实测

做法：打标模式 100Hz 记 ctX/ctY/ctZ；同一次采集里前 30s 夹空气、后 30s 夹 4cm 方块，
保证两次摆放位置相同（分开采会被位置差淹没：空握 X 中位数一次 401、另一次 585~677）。

| 轮 | 组 | X | Y | Z | dev |
|:--:|---|---:|---:|---:|---:|
| 1 | 空握 | 585~677 | -79 ~ -69 | 1551~1677 | 1694~1777 |
| 1 | 夹物 | 681~695 | -87 -> +62 ~ +72 | 1511~1540 | 1664~1687 |
| 2 | 空握 | 268 | -19.6 | 1590 | 1613 |
| 2 | 夹物 | 252 | +139.1 | 1428 | 1487 |

两轮一致的趋势：夹物时 Y +140~160mg、Z -110~165mg，dev 略降。

为什么还不能当判据：

1. 组内标准差：Y 空握 10~19mg、夹物 69~119mg（第 1 轮夹物还是双峰 -87/+62），夹物离散度与空握到夹物的位移约 150mg 同量级；
2. 分段窗口混进开合过渡（Z 标准差 640~700mg），说明手动保持稳态并不严格；
3. 效应折算约 9 度，与 H2 的 11~24 度同量级。

判断：三轴向量比单看角度多一路信息（方向而非模长），趋势稳定但余量太薄。
要继续必须先把每次保持的姿态做成可重复（机械限位），在此之前只能当辅助特征。

## 19. 无机械限位时的兜底：自动重采基准

已实现并烧录（commit 1ec9554）。

### 19.1 规则

每完成一次闭合后，若：静止 >= 2000ms、幅值 < 100mg、闭合角 < 8 度，
则清基准并自动重采一次（等于替操作员按了一次 t），随后 s_sinceClose 清零。

三个条件缺一不可：只看静止会把夹着物体停住当成张开位；只看角度会在还没回位时清零；只看幅值会在运动中采基准。

### 19.2 参数调整

| 宏 | 原值 | 新值 | 理由 |
|---|---:|---:|---|
| OPEN_D_MG | 280 | 400 | 张开态实测 3~212mg，闭合态 >1000mg |
| GYRO_STILL_MS | 300 | 500 | 减少闭合途中停顿被当成张开 |

### 19.3 实现中踩的坑

第一版没有每个闭合周期只重采一次的限制，结果静止时每 2 秒反复清基准再重采，
D 在 ? 和 0 之间周期跳动。修法两条：

1. 加 s_sinceClose，只有闭合过才允许重采一次；
2. flatRefCommit 成功时把 s_stillUs 归零，避免采集过程累积的静置时间立刻再次触发。

### 19.4 验证

- gyro_test 6/6 通过（G7 十次开合归零仍成立）
- 固件 363944 B / 30116 B RAM / 0 warning，已烧录
- 实板静置 10 秒连续 6 次采样：D = 3/3/3/2/0/4 mg，不再出现 ? 抖动

## 20. 机械限位方案，以及"做不到"时的边界

> 本节只记录方案，不改变当前 v5 判据。机械限位解决的是**每轮张开零位不一致**，
> 不是用限位去区分空夹与夹物。

### 20.1 限位应加在哪

现阶段优先限制**张开起始位**，闭合止位只作为后续机械实验分支：

- 张开止位让每轮从同一姿态开始，角度积分和 Y/Z 静态特征才有可比性。
- 闭合止位理论上是让"空握停在固定止位、夹物提前被物体挡住"，可拉开角度差；
  但它会改变夹持力和物体受力，必须单独验证，不能直接加到最终结构上。

### 20.2 试验阶段的最小做法

| 部件 | 做法 | 目的 |
|---|---|---|
| 张开止位 | 在中指根部或手背侧固定一个薄尼龙/3D 打印 L 形挡块，圆角接触手指 | 手指自然回弹时停在同一角度 |
| 回位弹簧 | 低刚度拉簧或橡皮筋连接手指根部与手背，拉力只需克服手指回弹 | 主动把手指带回止位 |
| 侧向导向 | 必要时加一片薄导向片，限制左右摆动 | 降低 Y/Z 的横向散布 |
| 应变释放 | 柔性板弯曲区附近留出活动余量，不让限位件压到柔性 PCB | 防止反复弯折损坏 |

建议先用可拆夹具验证，不直接改最终机械结构。夹具不能遮住指甲盖上的检测模块，
不能给指尖增加额外预紧力，也不能碰到振源或被测物体。

### 20.3 加限位后的验收

先做 10 次空开合，每次松手后停 2 s 再闭合，至少检查：

1. 张开位 `ang` 的极差；
2. 张开位 `D` 的极差；
3. 同一动作的 Y/Z 静态均值与组内标准差；
4. 与夹物组的类间距离是否达到组内标准差的 3 倍。

只有重复性明显改善，才重新评估 `touchScore`。限位件本身不能改变夹物时的接触位置，
否则测到的是夹具，不是手指。

### 20.4 如果机械限位做不到

软件兜底已经实现并烧录（commit `1ec9554`）：

```text
本闭合周期闭合过
且静止 >= 2000 ms
且幅值 < 100 mg
且闭合角 < 8 deg
=> 清平放基准并自动重采一次
```

同时：

| 宏 | 当前值 | 作用 |
|---|---:|---|
| `OPEN_D_MG` | 400 | 区分"回到张开位"与闭合位 |
| `GYRO_STILL_MS` | 500 | 防止闭合途中短暂停顿被当成张开 |
| `AUTO_ZERO_REST_MS` | 2000 | 自动重采前要求的静止时间 |
| `AUTO_ZERO_AMP_MG` | 100 | 排除"夹着物体静止"时误重采 |
| `AUTO_ZERO_ANGLE_DEG` | 8 | 排除尚未回位时误重采 |

兜底只能把**当前张开姿态**当作新的零点，不能消除不同张开位置造成的 Y/Z 差异。
因此没有机械限位时：

- 松手/闭合仍可由陀螺角判断；
- 接触仍只认"闭合 + 幅值 + 主频"；
- 闭合但无振动证据时只能报"不知道有没有物体"，不能报"握紧无物"；
- `touchScore` 继续保持诊断/实验性质，不接入最终 `contact`。

### 20.5 回退顺序

如果机械重复性无法改善，且 v5 的实板统计验收不能稳定通过：

1. 保留 v5 的"角度判闭合 + A/F 判接触"作为候选；
2. 回退到 v4 的 `CT_MODE=3` 稳定判据；
3. 再不行回退到 v3 的 `CT_MODE=2`。

回退前先确认失败是机械重复性、振源耦合还是算法阈值，不能只凭单次数据切换版本。
