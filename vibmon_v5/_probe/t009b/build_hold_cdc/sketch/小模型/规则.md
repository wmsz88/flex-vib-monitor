## 一、开工检查清单（每次会话必做，按顺序）

| 步骤 | 读什么 | 目的 |
|:--:|---|---|
| 1 | `AGENTS.md` | 确认角色、写权限、目录结构 |
| 2 | `小模型/规则.md`（即本文件） | 确认行为规范 |
| 3 | `规划/tasks/` 中状态为 `todo` 的任务卡 | 领取任务 |

**只有 `todo` 状态的卡可以领。** `doing` 说明另一侧正在执行，不能抢。

## 二、执行会话的标准流程

```
读任务卡 → 改代码 → 编译验证 → 保存/导出数据 → 写结果文件 → 任务卡状态不改（那是规划侧的事）
```

### 2.1 读任务卡

要看清这四样：
- **目标**：要做什么
- **涉及文件**：可以改哪些文件
- **验收标准**：做到什么程度算完成
- **要求回传的数据**：必须在结果文件里输出什么

### 2.2 改代码

- **只能改**：`*.h` `*.cpp` `*.ino` 等根目录代码文件 + `data/` `test/` `_probe/`
- **绝对不能改**：`规划/` 整个文件夹（含 plan.md 和 tasks/）——这是禁区！
- **绝对不能改**：`大模型/` 整个文件夹
- 可以读但不能改：`大模型/`、`小模型/规则.md` 以外的 `小模型/` 文件

### 2.3 编译验证

用本机 Arduino CLI：
```powershell
$cli = "C:\Users\Lenovo\AppData\Local\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe"
$src = "D:\大学\课程\工科赛\代码\vibmon_v5"

# CDC 构建（比赛用）
& $cli compile --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" $src --warnings all

# 非 CDC 构建（验证用）
& $cli compile --fqbn "esp32:esp32:esp32c3" $src --warnings all
```

必须 **0 warning** 才算通过。

### 2.4 宿主测试

改完 `state.cpp` 后必须重跑：
```powershell
g++ -std=c++17 -Wall ... test/contact_test.cpp ...
g++ -std=c++17 -Wall ... test/gyro_test.cpp ...
g++ -std=c++17 -Wall ... test/comp_frame_test.cpp ...
```

改完 `dsp.cpp` 后不一定有对应的宿主测试，需额外注意。

### 2.5 写结果文件

任务结束后，按 `结果/_结果模板.md` 格式，在 `结果/` 写 `RTxxx-YYYYMMDD.md`。

**结果文件只能写三样（铁律）**：
1. 做了什么（文件级改动）
2. 测到什么（数据）
3. 结论是什么

**禁止在结果文件里写**：
- "建议下一步……"
- "应该……"
- 任何规划/方向性内容 —— 那是规划侧的权力

## 四、常见坑（必读）

| 坑 | 说明 |
|---|---|
| C++20 volatile 警告 | `volatile` 变量上 `++` / `--` 报 `-Wvolatile`，要写成 `x = x + 1` |
| CDC 构建必须 | 烧录用 `CDCOnBoot=cdc`，否则 USB CDC 串口不工作 |
| 非 CDC 模式 GPIO 冲突 | 非 CDC 下 Serial 占 UART0(GPIO20/21)，与比赛口冲突 |
| COMP_FRAME_ENABLED | 当前冻结为 1，比赛口 50Hz 发送。改回 0 需同步改文档 |
| stateReset 不清参考点 | 接触姿态/平放基准跨 reset 保留，这是设计决策不是 bug |
| plan.md 禁区 | 连读可以，改一个字都不行。改了会被规划侧回滚 |

## 五、比赛帧格式参考

当前帧（35 字节）：
```
$VD,SEQ,FREQx10,AMP_MG,VIB,CT,SSx100,VALID,CHK\r\n
```

| 字段 | 含义 | 编码 |
|---|---|---|
| SEQ | 帧序号 0~9999 | 4 位 |
| FREQx10 | 主频×10，无效=0 | 5 位 |
| AMP_MG | 幅值 mg，无效=0 | 5 位 |
| VIB | 振动状态 0/1 | 1 位 |
| CT | 接触状态 0/1 | 1 位 |
| SSx100 | 启停频率×100，无效=0 | 3 位 |
| VALID | 有效性位图 0-F | 1 位 hex |
| CHK | 正文 XOR 校验 | 2 位 hex |

VALID 位图：bit0=ampValid, bit1=freqValid, bit2=ssValid, bit3=contactValid

注意：`closed`（手指是否闭合）**不在帧里**。平台看到 CT=0 时不知道是"手没合"还是"手合了但没振动"。这是已知的设计限制，见 `小模型/检验方案.md` 建议 1。
