# vibmon_v5 答辩问答预案

> 署名：2026-11-03 · Codex(flash) ｜ 每条含"一句话回答 + 依据来源"

**Q1 为什么不做"无振动状态下的接触"检测？**
A：命题要求的是"检测接触状态 + 目标物体持续/周期振动"，测试件始终带可控振动激励；历届六年（2021~2026）也无一届要求无振动接触。合拢不误判由 CL 字段承载。
依据：结果/RT003-20261102.md；小模型/检验方案.md。

**Q2 "握住后置零/接触保持"看起来像会锁死，是 bug 吗？**
A：不是。进入需姿态+幅值+频率三证齐全，保持只需姿态加上振动类证据任一——这是为防止平台间歇激励把一次握持切碎的有意设计；实测关源时两路证据同时失效、0.42s 正常退出。
依据：结果/RT005-20261102.md；state.cpp:264-275。

**Q3 180Hz 端点测到了吗？**
A：本地稳态激励上限 175.7Hz（新方块连续 8s），180Hz 无稳定本地激励源；但测频链路有 201.4Hz 瞬态实测背书，远超赛题上限，传感器侧无缺陷。
依据：结果/RT006-20261102.md；vib_range_test/data/startstop_live_20261102_fixed.csv。

**Q4 测频精度多少？**
A：稳态 77~175.7Hz 段内 F 读数与振源一致（±5Hz 量级，见 T005/RT006 逐档表）；启停频率 0.5/1/2/3Hz 四档实测 0.50~0.53 / 1.00~1.01 / 1.99~2.02 / 2.92~3.00。
依据：结果/RT005、RT006；vib_range_test/data/startstop_live_20261102_final2.csv。

**Q5 和同赛项其他队的主要差异？**
A：别人多为"频带 RMS + 过零频率"二重与，没有接触判定；我们有姿态+幅值+频率三重 CT 判据、CL 闭合字段、D 命令 24 列诊断三样独有增量。
依据：结果/RT003-20261102.md。

**Q6 比赛帧怎么和平台对接？如果平台格式固定？**
A：帧默认 35 字节，与改动前逐字节一致；若平台允许加字段，一行配置打开 CL 变 37 字节（CL 在 CT 后、校验覆盖）；若平台锁定 35 字节，就结合现场观察区分"松手/空握"。
依据：结果/RT001-20261102.md。

**Q7 启停（0~3Hz）是怎么测的？**
A：主频停留时长统计——振动段/停止段交替，板内定时器按固定周期通断产生标准激励，固件据此估启停频率，四档实测落在 0.5/1/2/3Hz 附近。
依据：vib_range_test/data/startstop_live_20261102_*.csv；小模型/检验方案.md。

**Q8 MPU6050 为什么够用？**
A：接触判据不依赖高带宽器件，而是"闭合角 + 带内幅值 + 主频"；70Hz 二阶高通后 ERM 振动主频清晰可估，实测跟踪到 201.4Hz。MPU6050 的 I2C 可靠性已留量化证据（静止60s/弯折3min 增量 0）。
依据：结果/RT004、RT005；大模型/评审报告_20261102.md。

**Q9 闭合角怎么算的？为什么不用 D 投影角？**
A：用陀螺积分角（±500dps，GYRO_FS_SEL=1→GYRO_CONFIG=0x08），静止时不积分（零速修正防漂移），回到 START 位由平放基准归零。单靠加速度 D 投影角分辨力不足，故改用陀螺积分。
依据：陀螺仪改造方案.md §2；结果/RT001（陀螺量程附注）。

**Q10 CT / CL 两个位到底什么语义？**
A：CL=1 表示"已握住"（姿态过门）；CT=1 表示"有接触证据"（姿态 + 幅值/频率）。所以 CL=1 且 CT=0 = 握住了但没振动证据（空握/无激励），CL=0 = 松手。
依据：结果/RT001、RT002、RT005。

**Q11 现场开不了机/一直判不到怎么办？**
A：先看 `S`：I2C错/读失败是否为 0、角度是否可信。常见坑：复位时必须张开静止在 START（否则角度基准废）；用 `P` 重采 START 基线、`t` 重采平放基准。D 命令可一列看出三路判据哪路卡住。
依据：结果/RT005、RT006；_probe/t005、t006 脚本与 README。

**Q12 为什么用占空比调频而不是调 PWM 频率？**
A：ERM 偏心转子马达，振动频率 = 转速/60，PWM 载波固定 20kHz（避开人耳），只调平均电压→转速；所以调振动频率靠调占空比。
依据：vibsource 固件 config.h（Desktop\STM32project\vibsource_esp32_dual）。
