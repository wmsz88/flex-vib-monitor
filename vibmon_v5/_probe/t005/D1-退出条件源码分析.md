# D1 接触退出条件 源码分析（T005）— 2026-11-02 · Codex(flash)

> 只读分析，不改固件。源码基线：当前工作区 `state.cpp` / `config.h`。

## 1. contact 退出/保持的完整规则（CT_MODE=4）

`combineContact()`（state.cpp:264-275）：

- **进入（prev=0）**：`postureOk && ampEff && freqEff` —— 三路同时成立。
- **保持（prev=1）**：`postureOk && (ampEff || freqEff)` —— 姿态必须在，振动类证据留一路即可。
- **退出**：其余情况，即 `!postureOk` 或 `(!ampEff && !freqEff)`。

调用处（state.cpp:435-438）传入的是**滞回保持位** `s_ampHeld` / `s_freqHeld`，不是瞬时 condAmp/condFreq：

| 输入 | 变量 | 来源 | 说明 |
|---|---|---|---|
| postureOk | `s_ctPostCmd` | gateStep(px, pon, poff) | 姿态滞回门 |
| ampOk | `s_ampHeld` | gateStep(_, ampMg, 400, 300) | 幅值滞回保持位 |
| freqOk | `s_freqHeld` | gateStep(_, freqHz, 75, 63) | 频率滞回保持位 |

有效性（CT_FLAT_DEGRADE_STRICT=1，config.h:411）：`ampEff=ampOk`、`freqEff=freqOk`；且当 `ampValid=false` 时 `s_ampHeld` **显式清零**（state.cpp:418-422），`freqValid=false` 时 `s_freqHeld` 显式清零（428-432）。所以“数据失效 = 该路证据当前不成立”。

任何翻转还要过确认延时 `CT_CONFIRM_MS=100ms`（state.cpp:464-466）。

## 3. T1 时序手工推演 vs 实测（run_p1 / r1_t1_pull）

实测行（elapsed_s: ct, A_mg, F_Hz）：

| t | ct | A | F | 推演 |
|---|---|---|---|---|
| 0.00 | 1 | 694 | 123 | ampHeld=1,freqHeld=1,posture=1 → 1 |
| 0.64 | 1 | 59 | 116 | amp 落<300 → ampHeld=0；**F 仍有效>75 → freqHeld=1 → 保持规则成立 → 1** |
| 1.06 | 1 | 18 | 117 | 同上：仅靠频率证据续命 → 1 |
| 1.70 | 0 | 11 | (无效) | freqValid=false → freqHeld=0；ampHeld 已 0 → **两路证据全无 → 退出** |
| 2.13/2.54 | 0 | 12/23 | (无效) | 维持 0 |
| 3.19 | 1 | 155 | 131 | 进入需三路；A 采样值 155<400，但轮到 3.19 之间出现 **瞬态 >400 将 ampHeld 重新锁为 1**；freq>75 → freqHeld=1；posture=1 → **重新进入** |
| 3.19~9.55 | 1 | 80~222 | 122~131 | 此后 amp 多在 300 以下（ampHeld 反复清/锁），但 **F 持续有效>63 → freqHeld=1 → 保持规则恒成立 → 锁到窗口尾** |

**推演与实测吻合。锁存主因规则 = 保持规则 `postureOk && (ampHeld || freqHeld)` 中「频率证据可单独续命」**，而 `freqHeld` 的退出下限只有 63Hz：抽走物体后残余/窜振仍能给出 115~131Hz 的“有效主频”，于是频率门一直为真。次要成因：幅值 `ampHeld` 进入门 400 经“瞬态锁存”会被余振重新拉高，触发再次进入。

## 4. 分歧点：卡的“证据②：dual 关源锁存 4s”与数据不符

T005 卡描述「dual_orig_off / dual_new_off 各 4s 段内 ct 全程保持 1，幅值中位 7~9mg」。**复核 `run_dual_dump/run.csv` 原始行不成立**：

| 段 | 行数 | ct 序列 |
|---|---|---|
| dual_orig_off | 8 | 0.00s=1（A=1015，电机惯性未停）→ 0.65s 起全 0（A≈5~14mg） |
| dual_new_off | 8 | 0.00s=1（A=215）→ 0.64s 起全 0（A≈5~11mg） |

即两段**关源后约 0.6s 就退出**，不存在 4s 锁存。唯一 ct=1 的是关源当刻那条（电机尚未停）。这与 D1 规则一致（amp 落<300 且 freq 无效 → 两路全无 → 退出）。

→ 结论：三份“锁存证据”经复核实际只有 **1 份成立（T1 余振锁存）**；dual 关源属**正常退出**（~0.6s）；A4 是**退出的耗时问题**（~0.42s，见 §5），与“锁存”不是同一现象。

## 5. A4 关源退出耗时 ~0.42s 的解释

关源瞬间 amp 仍 >300（电机惯性），ampHeld 保持 1；随电机减速 amp 落 <300 → ampHeld=0；freq 同时变无效 → 两路全无 → 再过 CT_CONFIRM_MS=100ms 确认 → ct=0。实测 0.42~0.43s ≈ 电机减速时间 + 100ms 确认。相对 0.5s 上限余量约 0.1s。
