## 本卡专用注意事项（来自项目实测记忆，flash 必读）

1. **测前采 START 基线**：每个测试 session 开始前按 `P` 采基线，动作顺序 START→FINISH→HONGEST→START；P 命令有防呆（闭合角>8° 或姿态偏差超限会被拒绝），被拒绝时让人类回到张开平放位再按，**不要绕过**。
2. **空握与夹物的终角只差 11~24°**（空握 111°、夹 4cm 方块 100°，机械重复性/装贴所限）：两者 `closed` 都会是 1，**区分完全靠幅值门（>400mg）**。若 A2 空握出现 ct=1 误报，第一嫌疑是装贴/机械状态变化，不要现场调阈值——记录数据即可。
3. **幅值门才是真正把关者**：空夹假频 86~169Hz 与真接触主频 157.8~179Hz 频段重叠，频率门单独区分不了；分析数据时按「幅值证据优先」判读。
4. 检验中 `[MPU] 无应答(寄存器 0x75)` 或 I2C 错误重现 ⇒ 如实记录并中止该轮，等待人类检查连接；不要反复重烧尝试"恢复"。
