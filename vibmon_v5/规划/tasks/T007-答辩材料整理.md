### 3. 设计定性（为什么这样设计——答辩必问）

- **接触保持规则（"锁存"）**：进入需三证齐全，保持只需姿态+幅值/频率任一——**有意设计**，防间歇激励时误退出（比赛激励由平台控制启停）。实测：关源两路证据同塌 0.42s 正常退出（RT005 D2 三次复现）；"锁存"证据仅 T1 一例（抽走物体但振源仍开的非比赛工况）。来源：RT005 + state.cpp:264-275
- **180Hz 端点**：本地稳态激励上限 175.7Hz（新方块），180Hz 无稳定本地激励源；测频能力有 162~172Hz 稳态 + 201.4Hz 瞬态背书，传感器侧无缺陷。来源：RT006 + T006 卡 23:44 补充
- **双轴架构**：θ>60° 判闭合 + A>400mg 且 F>75Hz 判接触；陀螺积分角（±500dps，GYRO_FS_SEL=1）解决 D 投影角分辨力不足。来源：陀螺仪改造方案.md + PLANNER-A 评审报告

### 4. 风险预案（现场 SOP）

- **平台帧格式未确认**：COMP_FRAME_CL 默认 0（逐字节兼容现状）；现场确认可调后一行配置打开（T001）
- **平台要求先不发数据**：COMP_FRAME_ENABLED 冻结 1，到场快速改 0 重烧（人工操作 SOP 已列 T001 验证项）
- **开机姿态**：复位后必须张开静止（不在 START 位 P 会被拒，t006_newblock 教训）
- **振源控制**：COM7 单字符协议；通道档案 a=低速 b=高速（T006 修正，勿再按旧标签）
