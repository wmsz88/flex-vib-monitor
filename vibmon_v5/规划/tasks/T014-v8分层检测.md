## 一、目标

在 V6 出发版基础上新建 **vibmon_v8**，把检测架构明确拆成两层：

1. **实时层**：输出当前 `VIB` / `CT`，50Hz，供比赛平台读取
2. **均匀/稳态层**：滑窗统计主频、幅值、启停频率，输出稳定性和离散度，供答辩与后续平台扩展

要求：

- V8 是**独立实验线**
- V6 最终版源码、预编译 `bin`、T013 验收状态全部不动
- V7 只作现场适配参考，不作为 V8 基线以外的直接来源
- V8 默认 `$VD` 帧仍为 35 字节，不改比赛帧
- 均匀层结果先走调试行，不进 `$VD`

## 三、代码改动范围

### A. 新增实时层与均匀层

新增两个模块：

```text
vibmon_v8\layered_detection.h
vibmon_v8\layered_detection.cpp
```

要求：

- `RealtimeDetector`
  - 输出 `vib` / `contact`
  - 保持与 V6 接触三条语义一致
  - 振动状态带 120/80mg 滞回
- `UniformDetector`
  - 滑窗统计主频、幅值、启停频率
  - 输出中位数、离散度、有效率
  - 输出 `stable`

可参考：

```text
赛前准备\10_软件解读与现场更改\代码示例\layered_detection.h
赛前准备\10_软件解读与现场更改\代码示例\layered_detection.cpp
赛前准备\10_软件解读与现场更改\代码示例\layered_detection_test.cpp
```

但集成时必须按 v8 命名与代码风格整理，不要直接粗暴复制未适配的示例。

### B. 接入点

建议修改：

```text
state.cpp
state.h
vibmon_v8.ino
output.cpp
```

接入要求：

1. `stateOnFrame()` 后构造 `InputFrame`
2. 同一帧分别送入 `RealtimeDetector` 和 `UniformDetector`
3. 不改变 V6 现有 `Result.contact/vib/ss/freq` 的取值
4. 新层输出仅作观测，不反向影响 V6 判据
5. `d` 调试模式下新增一行：

```text
#LAYER vib= ct= stable= fmed= fspread= amed= aspread= ssmed= valid=
```

字段含义：

| 字段 | 含义 |
|---|---|
| `vib` | 实时层振动状态 |
| `ct` | 实时层接触状态 |
| `stable` | 均匀层是否稳定 |
| `fmed` | 滑窗主频中位数 |
| `fspread` | 主频离散度 |
| `amed` | 滑窗幅值中位数 |
| `aspread` | 幅值离散度 |
| `ssmed` | 滑窗启停频率中位数 |
| `valid` | 有效样本百分比 |

### C. 配置宏

`config.h` 新增：

```c
#define LAYERED_DETECT_ENABLE  1

#define LAYER_FREQ_SPREAD_MAX  0.08f
```

要求：

- `LAYERED_DETECT_ENABLE=0` 时编译无新增调试行，行为与 V6 相同
- 编译期断言参数合法
- 不引入堆分配
- 不阻塞主循环
