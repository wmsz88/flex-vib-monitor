# 比赛现场输出文档

> 固件：vibmon_v5　串口：115200, 8N1
> 用途：现场调试、平台对接、比赛帧输出说明
> 状态：比赛帧默认关闭，待与测试平台核对后启用

---

## 1. 现场连接

### 1.1 电源

| 项目 | 要求 |
|---|---|
| 输入电压 | 12V DC |
| 输出 | 约 5V 给 ESP32-C3 与 MPU6050 |
| 总开关 | 串接在稳压前端，断开后整板完全断电 |

上电前检查：

1. 4pin 线序正确：①TX、②RX、③GND、④VIN；
2. 12V 正负极没有接反；
3. 红色 LED 常亮，表示 5V 输出正常；
4. 绿色 LED 由固件控制闪烁，表示系统运行。

### 1.2 串口

| 项目 | 值 |
|---|---|
| 电平 | TTL 3.3V |
| 波特率 | 115200 |
| 数据格式 | 8N1 |
| 流控 | 无 |

连接：

```text
平台 RX ← 模块 ①TX
平台 TX → 模块 ②RX
平台 GND ↔ 模块 ③GND
平台 12V → 模块 ④VIN
```

## 2. 现场命令

调试串口支持单字符命令：

| 命令 | 作用 |
|:--:|---|
| `S` | 输出完整状态 |
| `w` | 输出一行 `#SWEEP` 采样结果 |
| `Q` | 输出一行 `#POST` 姿态诊断 |
| `T` | 输出采样与耗时统计 |
| `P` | 重采 START 姿态基线 |
| `c` | 重新标定，要求模块静置 |
| `d` | 开关调试行 |
| `0`~`4` | 选择绘图组 |
| `K` | 退出打标模式 |

---

## 3. `#SWEEP` 调试行

按 `w` 输出一行：

```text
#SWEEP t=12s F= 165.2Hz A=  965.7mg D= 1615mg ang=  119deg tr=   12mg vib=1 ct=1 grip=0 cl=1 w=0.8 cliplim=0 ax=2 ok=1
```

字段定义：

| 字段 | 含义 |
|---|---|
| `t` | 上电以来时间，秒 |
| `F` | 持续振动主频，Hz；无效时输出 `?` |
| `A` | 三轴合成振动包络，mg；无效时输出 `?` |
| `D` | 当前姿态到张开基准的偏差，mg |
| `ang` | 陀螺积分闭合角，度 |
| `tr` | 基准采集窗口极差 |
| `vib` | 持续振动状态，0/1 |
| `ct` | 接触判定，0/1 |
| `grip` | 诊断位：已闭合但未形成接触共振 |
| `cl` | 已闭合，0/1 |
| `w` | 三轴合成角速度，dps |
| `cliplim` | 主频是否受削顶降级 |
| `ax` | 主频估计使用轴，0=X，1=Y，2=Z |
| `ok` | 本行 F/A 是否可作为有效数据 |

现场快速判断：

```text
接触成功：ang>60，A>400，F>120，ct=1
空握/静止：ang>60，A 小或 F 无效，ct=0
松手：ang<45，ct=0
```

## 4. `#POST` 姿态诊断行

按 `Q` 输出：

```text
#POST cal=1 act=0 valid=1 cls=2 d=1680.0 x=... y=... z=... bx=... by=... bz=... clsd=2 stable=1 scnt=3 n=500
```

字段定义：

| 字段 | 含义 |
|---|---|
| `cal` | START 基线是否有效 |
| `act` | 是否正在采集基线 |
| `valid` | 当前姿态窗口是否有效 |
| `cls` | 当前姿态分类：0=UNKNOWN，1=START，2=HONGEST |
| `d` | 当前三轴均值到 START 基线的距离，mg |
| `x/y/z` | 当前三轴均值 |
| `bx/by/bz` | START 基线 |
| `clsd` | 防抖后的稳定分类 |
| `stable` | 是否满足静止条件 |
| `scnt` | 连续稳定窗口计数 |
| `n` | 当前窗口样本数 |

该诊断只用于确认机械位置，不参与正式接触判定。

## 5. 现场上电流程

### 5.1 标定

上电后模块需要静置标定，不要立刻移动：

```text
上电
  -> 保持张开/静止
  -> 自动加速度与陀螺标定
  -> 自动采集张开姿态基准
  -> 绿灯闪烁，串口输出状态
```

标定期间避免：

- 手指开合；
- 撞击桌面；
- 移动机械手；
- 强烈晃动模块。

### 5.2 检查

标定完成后发送 `S`，重点确认：

1. 传感器在线；
2. 标定有效；
3. 陀螺零偏正常；
4. `I2C错=0`；
5. `读失败=0`；
6. `不连续=0`。

### 5.3 动作测试

推荐顺序：

```text
1. 保持 START，发 S，确认 ang≈0
2. 闭合空握，发 S，确认 cl=1、ct=0
3. 接触振源，发 S，确认 A/F 过门、ct=1
4. 关闭振源，确认 ct 在短时间内回到 0
5. 回到 START，确认 cl=0
```

任何一步出现：

```text
[FAULT] 传感器无响应
A=?
ang=?
```

本轮数据作废，先检查接线和焊点。

## 6. 比赛帧输出

### 6.1 帧格式

比赛帧为 35 字节 ASCII 定长帧：

```text
$VD,SEQ,FREQx10,AMP_MG,VIB,CT,SSx100,VALID,CHK\r\n
```

字段：

| 字段 | 宽度 | 含义 |
|---|:--:|---|
| `$VD` | 3 | 帧头 |
| `SEQ` | 4 | 帧序号，0000~9999 回绕 |
| `FREQx10` | 5 | 主频 ×10 |
| `AMP_MG` | 5 | 振动幅值，单位 mg |
| `VIB` | 1 | 持续振动状态 |
| `CT` | 1 | 接触状态 |
| `SSx100` | 3 | 启停频率 ×100 |
| `VALID` | 1 | 有效性位图 |
| `CHK` | 2 | XOR 校验 |

示例：

```text
$VD,0137,01652,00966,1,1,120,F,63
```

### 6.2 VALID 位图

| bit | 含义 |
|:--:|---|
| 0 | 幅值有效 |
| 1 | 主频有效 |
| 2 | 启停频率有效 |
| 3 | 接触判定可信 |

十六进制表示：

```text
0 = 全部无效
1 = 仅幅值有效
7 = 幅值、主频、启停有效，接触不可信
F = 全部有效
```

### 6.3 校验算法

对从 `$` 到 `VALID` 的正文逐字节异或：

```c
uint8_t xorChk(const char *s, int n) {
  uint8_t x = 0;
  for (int i = 0; i < n; i++) x ^= (uint8_t)s[i];
  return x;
}
```

校验结果以 2 位大写十六进制输出。

### 6.4 启用比赛帧

当前固件默认 `COMP_FRAME_ENABLED=0`，比赛口静默。
与平台确认后，将 `config.h` 中的 `COMP_FRAME_ENABLED` 由 `0` 改为 `1`，再重新编译烧录。

## 7. 现场故障排查

| 现象 | 优先检查 |
|---|---|
| 红 LED 不亮 | 12V 输入、开关、AMS1117 输出 |
| 绿 LED 不亮 | 固件是否运行、LED 极性、绿灯 VF 偏高 |
| 无串口输出 | TX/RX 接反、波特率、USB CDC 烧录配置 |
| `I2C错` 增加 | SDA/SCL 焊点、排线、接插件、弯曲应力 |
| `A=?` / `ang=?` | MPU6050 掉线，本轮数据作废 |
| `ct` 一直为 0 | 幅值不足、主频无效、未真正压住振源 |
| `ct` 误报 | 检查 `cliplim`、主频窗口、机械瞬态振动 |

恢复测试门槛：

```text
静止 30s：I2C错=0、读失败=0、不连续=0
动态弯折 30s：仍为 0，且无 [FAULT]
```

## 8. 现场输出语义

正式验收只使用三态：

```text
松手
已闭合、无振动接触
接触振动
```

不要把 `grip` 当作第四个验收状态。它是诊断位，表示“已闭合但振动特征不足以证明接触”。

当前版本必须明确说明：

```text
接触 = 已闭合 + 幅值过门 + 主频过门
静止接触 = 无法证明，固件保守输出 ct=0
```
