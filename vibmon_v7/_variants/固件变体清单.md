**`.bin` SHA 的用法**：ESP32 的 `.bin` 里嵌了编译时刻与 ELF 指纹，同一份源码两次编译 SHA **必然不同**（T013 实测差 68 字节）。所以上表的 SHA 只用来对"我手里这份存档文件"做完整性核对；**认固件版本请看变体名 + 上面两个源文件的 SHA-256**，不要拿它跟重新编译的产物比对。

**编译方式的一点提醒**：这 7 个变体不要并行编 —— 第一次 7 个一起编时 `gate` 失败了一次（`Error during build: exit status 1`，无编译错误信息），单独重编就 0 warning 通过；多个 arduino-cli 同时写同一个 `Arduino15` 构建缓存会互相踩。要并行就把 `--build-cache` 指到各自的目录。

## 二、怎么烧

```bash
# 比赛用（CDC 构建，6 个 CDC 变体都这么烧）；COMx 换成实际口
arduino-cli upload -p COMx --fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc --input-dir "<本目录>\def"

# uart 变体（非 CDC）
arduino-cli upload -p COMx --fqbn esp32:esp32:esp32c3 --input-dir "<本目录>\uart"
```

急着用整片镜像时也可以用 `.merged.bin`（本目录没放，需要时同名目录重新编译会生成），
或直接 `esptool write_flash` 按 `flash_args` 的四个偏移写。

## 三、怎么重新编出这些变体

1. 把 `代码\vibmon_v7\` 的 `*.ino`、`*.h`、`*.cpp` 拷到一个**不含中文**的临时目录（文件夹名保持 `vibmon_v7`）；
2. 编默认版：

```bash
arduino-cli compile --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --warnings all "<临时目录>/vibmon_v7"
```

3. 编变体就在上面加 `--build-property "compiler.cpp.extra_flags=-D<宏>=<值>"`，宏见上表。

> 也可以不改宏、直接改 `代码\vibmon_v7\config.h` 里的默认值再编默认版 —— 结果等价，但记得改回来。
