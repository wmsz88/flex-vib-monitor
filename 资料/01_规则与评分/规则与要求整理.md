## 一、赛项背景

- 面向仿生手"柔性感知"应用：仿生手接触目标物体时，需实时感知接触状态、接触稳定性及目标物体微振动特征。
- 仿生手表面为弧面结构，传统刚性电路难以稳定贴合、振动信号易衰减，因此需采用**柔性PCB + 弧形结构贴合设计**。
- 模块工作原理：外部电源供电 → 仿生手单指接触带振动激励的目标物体 → 振动经接触面传导至柔性振动检测模块 → 板载传感器实时采集 → 单片机数据处理与频率检测 → **串口输出**给外部测试平台。
- 模块设有供电接口，并预留 4pin 标准接口（电源2pin + 串口信号2pin）。
- 仿生手单指宽度约 **13mm**。

## 二、竞赛任务

参赛队需完成：

1. 检测模块**柔性PCB（PI基底）的设计及制作**（设计由队伍完成，制板由组委会统一制作）；
2. **元器件焊接和组装**；
3. 接上电源后完成**程序编写和调试**。

组委会现场提供的物料包用于模块的组装、结构集成和程序调试。

- **物料限制**：参赛作品必须**全部采用组委会发放的物料**制作；使用非组委会发放的物料 → **取消比赛资格**。
- **PCB设计提交**：校内完成柔性PCB设计并按规定时间/方式提交组委会评审，由组委会统一制作柔性PCB。
  - 设计不符合要求无法制板的队伍 → **不参加后续现场比赛**。
- **现场实践环节**：向PCB设计合格的队伍发放其设计并制作好的柔性PCB板和物料包，在规定时间内完成焊接、组装、程序开发和调试。
- **备用方案（惩罚性规则）**：柔性PCB不能正常工作、或放弃使用自己设计的PCB的队伍，可选用组委会提供的标准柔性PCB板和物料包完成焊接、程序开发、调试，但**扣除总分的50%**。

## 五、检测模块功能要求（第一环节设计内容）

### 功能指标

- 检测仿生手与目标物体的**接触状态**、目标物体的**持续振动或周期振动**。
- 需检测：
  - **持续振动频率：80Hz ~ 180Hz**
  - **启停频率：0 ~ 3Hz**（某固定频率振动状态与无振动状态组成的周期频率）

### 硬件架构要求

- 基**于ESP32-C3单片机模块 + MPU6050传感器模块，以柔性电路板为基础。**
- **ESP32-C3 通过 I2C 连接 MPU6050，实时读取加速度计信息，单片机完成数据处理与频率解析。**
- **稳压电路：输入 12V → 输出 5V（单片机和传感器供电）。**
  - **红色LED常亮 表征稳压输出正常；**
  - **绿色LED由单片机控制闪烁，显示电路正常运**行。
- **电源总开关**：串联在12V转5V稳压电路**前端**；断开时模块**完全断电，不得存在静态功耗**。
- **黄色LED**：需预留并可控制亮灭。
- 供电：组委会提供 **12V** 电源；电源接口采用**杜邦线方式**连接，通过指定焊盘预留焊接位置，**现场焊接杜邦线**。
- 串口：TTL电平，杜邦线方式连接，指定焊盘预留焊接位置，现场焊接。

### 4pin 标准接口要求

- 采用 **4个开窗焊盘**（每个开窗尺寸 **> 4mm × 2mm**）。
- 焊接 4 根 **30mm 公头杜邦线**作为电源与串口连接线（更新版正文写"30CM"，但表1 封装规格为"单公头 30mm"，以表1 为准）。
- **线序以命题图 3 为准：①TX ②RX ③GND ④VIN**。  
  （更新版已删除旧版正文中"线序依次为 VIN、GND、TXD、RXD"的矛盾表述，图 3 新旧版本一致，  
  与本项目网表 `U4.1=TX / U4.2=RX / U4.3=GND / U4.4=VIN` 完全吻合，PCB 无需改动。）

### 尺寸与外形

- 整体外形参考组委会提供的标准外框，**最大不超过 100mm(长) × 25mm(宽)**。  
  更新版图 4 实测：**总长 90.0mm = 左段 55.0mm（高 22.3mm）+ 右段 35.0mm（高 12.6mm）**，  
  15.2mm 强制弯曲避让区**嵌在右段起始处**（即右段净剩 19.8mm × 12.6mm 放器件）。
- **强制弯曲避让区**（外框图中黄色边框区域）：**严禁放置任何元器件**，只允许电气布线与过孔。
- 柔性PCB须能完整贴合组委会提供的标准弧形仿生手单指结构表面，需考虑弯曲区域设计。

## 八、PCB设计规范（硬性制板要求）

1. **物料**：只能使用《物料清单》中的物料。
2. **板框**：放置在 **Keep-Out Layer（GKO）**；必须为**闭合图案**、线条宽度一致、**有且只有1个边框**；除边框外GKO层不能有其他任何图案。非闭合边框或超尺寸 → 不予制作。
3. **层与文件**：
   - 双面板至少包含：`GKO`、`GTL`、`GBL`、孔层（`TXT/DRL`）共 **4个文件**；
   - 单面板至少包含：`GKO`、`GTL/GBL`、孔层（`TXT/DRL`）共 **3个文件**。
4. **线宽与间距**：
   - 最小线宽 / 最小线间距（线边缘间距）：**10mil (0.254mm)**
   - 最大线宽：**100mil (2.54mm)**
   - 元器件最小间距：**20mil (0.508mm)**
   - 导线-焊盘、导线-过孔、焊盘-焊盘、过孔-过孔、焊盘-过孔间距：**≥ 10mil (0.254mm)**
   - 导线/过孔/焊盘 与 边框间距：**≥ 12mil (0.305mm)**
   - 单个封装内：焊盘宽度 ≥ 12mil (0.305mm)，焊盘中心间距 ≥ 25mil (0.635mm)，焊盘边缘间距 ≥ 12mil (0.305mm)
   - 板载连接器引脚最小间距：**≥ 100mil (2.54mm)**
   - 超范围 → 不予制作
5. **孔的规格（只有3种，全部圆形）**：
   - 插件焊盘（通孔）：内径 **47mil (1.20mm)**，外径 **90mil (2.3mm)**
   - 过孔：内径只有 **25mil (0.635mm)** 一种，外径 ≥ **45mil (1.143mm)**
   - 固定孔：以过孔形式放置，孔内径只能为 **118mil (3mm)**
   - 其他尺寸/形状的过孔、钻孔、通孔 → **一概不予制作**
6. **禁止铺铜**：所有电气连接均以走线（Track）方式连通，**不可使用铺铜（Poly）**，否则不予制作。

## 九、关键模块说明

### ESP32-C3 单片机模块

- 32位 RISC-V CPU，含FPU，支持单精度浮点；Wi-Fi/蓝牙双模。
- 组委会提供**扩展封装板**：单片机已焊好，13个引脚以**邮票孔**引出，脚间距 **2.54mm**，模块尺寸 **19mm × 23mm**。
- 板上有 RESET 按钮和 BOOT 按钮；用 **USB Type-C** 连接即可烧录。
- **进入下载模式**：按住BOOT → 按下RESET → 松开RESET → 松开BOOT。
- Layout时参考"封装库"文件中的封装。
- **禁止布线区**：为防止模块板后Type-C连接器部位两侧与PCB短接，需在PCB对应网格区域禁止布线（见命题图7）。

### MPU6050 传感器模块

- 集成外围LDO、I2C上拉电阻；3轴陀螺仪 + 3轴加速度计，各3个16位ADC。
- 扩展封装板：I2C引脚及控制引脚**邮票孔**引出，脚间距 2.54mm，尺寸 **14.86mm × 11.5mm**，工作电压 **5V**。

| 引脚号 | 名称     | 类型  | 功能                   |
| --- | ------ | --- | -------------------- |
| 1   | VCC    | 电源  | 电源输入，接5V             |
| 2   | GND    | 电源  | 电源地                  |
| 3   | SCL    | I/O | I2C时钟，内置5.1K上拉       |
| 4   | SDA    | I/O | I2C数据，内置5.1K上拉       |
| 5   | AD0    | I/O | I2C地址配置脚             |
| 6   | AUX_CL | I/O | 主机I2C时钟接口（接外部传感器SCL） |
| 7   | AUX_DA | I/O | 主机I2C数据接口（接外部传感器SDA） |
| 8   | INT    | I/O | 中断输出脚                |

### 三灯状态与绿灯现场预案（2026-09-29 决策：不改板）

| 灯 | 驱动                                      | 状态含义              |
| - | --------------------------------------- | ----------------- |
| 红 | 硬件直连 5V 常亮（+5V→R3→LED3→GND），软件不可控       | 稳压输出正常            |
| 绿 | **GPIO10 → R7(120Ω) → LED1 → GND**（拉电流） | MCU 控制闪烁 = 电路正常运行 |
| 黄 | GPIO5 → R8(360Ω) → LED2 → GND（预留可控）     | 固件赋予"检测到持续振动"语义   |

**绿灯风险**（更新版表1 官方规格：绿 VF 2.5~3.6V @20mA）：VF 上限 3.6V 高于 GPIO 高电平 3.3V。  
典型 VF≈3.0V 时电流约 (3.3−3.0)/120Ω ≈ 2.5mA，偏暗但肉眼可辨，赛题只考核"闪烁"行为，**决定不改板**。

**现场预案（若绿灯不亮/极暗，按序执行）**：

1. 断电，先换上剩余的备件绿灯（清单每色 2 颗，本设计各用 1 颗）再观察——可能只是器件 VF 离散；
2. 仍不亮 → 飞线改灌电流：LED 反接（阳极改接 5V 轨、阴极经 R7 接 GPIO10），R7 由 120Ω 换 360Ω  
   （(5−3.0)/360 ≈ 5.6mA，同封装直接换料，均在清单内）；
3. 固件把 `LED_ACTIVE_LOW` 宏改为 `1` 重新编译烧录（`代码\vibmon\vibmon.ino` / `selftest.ino` 顶部配置区）。
