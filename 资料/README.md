## 阅读顺序建议

1. `背景与题目.md`（在仓库根目录）——先知道比赛要做什么；
2. `01_规则与评分/规则与要求整理.md`——逐条看硬性要求；
3. `00_命题/柔性检测模块设计及制作赛项命题（更新版）.pdf`——看原图与尺寸；
4. `02_硬件设计/硬件设计说明/07-pinout.md`——确认引脚；
5. `03_软件与方案/版本讲解/v5到v9说明书.md`——再看代码。
