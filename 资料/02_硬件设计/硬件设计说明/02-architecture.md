# 02 架构 — 柔性振动检测模块

**日期**：2026-09-20

## 为什么不做三方案对比

标准流程要求"国产/海外/混合"三候选架构，但本赛题命题**直接锁定**了主控（ESP32-C3）、传感器（MPU6050）、电源芯片（AMS1117-ADJ）与全部被动件——引入任何清单外器件即取消资格。因此架构自由度不在"选什么芯片"，而在以下三个**真正可取舍的维度**：

## 取舍一：稳压反馈电阻（决定输出电压精度）

Vout = 1.25V × (1 + R2/R1) + Iadj×R2（Iadj ≈ 50µA，AMS1117-ADJ 数据手册）

| 方案 | R1 | R2 | Vout（典型） | 分流损耗 | 评价 |
|---|---|---|---|---|---|
| **A（推荐）** | 120Ω | 360Ω | **5.02V** | 10.4mA | 精度最高（+0.4%），Iadj 误差被小阻值吸收；多耗约 70mW，对 12V 供电台架设备无影响 |
| B | 1K∥1K=500Ω | 1.5K | 5.08V | 2.5mA | 精度好（+1.5%），省电，用 3 颗电阻 |
| C | 1K | 3K | 5.15V | 1.25mA | 最省器件，但 +3% 偏高，且误差是系统性的（评审测量会看出来） |

**选 A**：理由是省下的 70mW 对系统无意义（主损耗在 LDO 压差），而输出精度是评委能直接测的指标。

## 取舍二：层数

- **双面板（推荐）**：正面放器件，背面走 I2C/电源跨线，弯曲区只有走线+过孔，布线宽松、直插焊盘好处理
- 单面板：制板文件少 1 个，但 22.5×18.0mm 模块（组委会封装实测）16 个邮票孔 + 4pin 大焊盘在同一层走线，弯曲区 15.2mm 跨区布线紧张，焊接返修也难

**选双面板**，Gerber 交 GKO/GTL/GBL/TXT 四件。

## 取舍三：MPU6050 位置（决定信号质量）

- **放在窄条上、紧贴弯曲避让区（推荐）**：振动经接触面→FPC→传感器路径最短，信号衰减最小；模块封装包围盒 18.67×9.14mm 放进避让区之后的 **19.8×12.6mm** 余量带——**横向只剩 1.13mm 总余量（每边 0.57mm，刚好过"与板框≥12mil"）**，是全板最紧的一处，必须紧贴弯曲区边缘摆、不能再留手工余量
- 放在主体 55×22.3 区：远离接触区，振动经长板传导衰减，80~180Hz 小信号可能被结构谐振污染

**选前者**。跨弯曲区只走 4 根线：5V、GND、SDA、SCL。

> 相比系统框图补齐的内容：① 4pin 大焊盘同时承担 12V 输入与串口输出（①VIN/②GND/③TXD/④RXD）；
> ② AMS1117-ADJ 的反馈网络（R1 120Ω/R2 360Ω/Cadj 10µF）与输入输出电容（CIN 10µF、Cout 22µF、0.1µF）落地到具体引脚；
> ③ 三路 LED 的限流电阻与驱动引脚（红=5V 常亮、绿=GPIO10 心跳、黄=GPIO5 预留）；
> ④ 弯曲避让区内仅 5V/GND/SDA/SCL 四线跨越。

电源链路与信号连接关系：

```
12V DC ──► 滑动开关 ──┬─ CIN 10µF ─► AMS1117-ADJ ─► 5V轨 ─┬─► ESP32-C3 模块(5V脚)
   (4pin VIN/GND)     │        R1=120Ω(Vout-ADJ)          ├─► MPU6050 模块 VCC
                      │        R2=360Ω(ADJ-GND)           ├─► 红LED+360Ω→GND（电源指示，常亮）
                      └─ Cadj 10µF(ADJ-GND)               └─► Cout 22µF + 0.1µF
                                                            │
ESP32-C3 GPIO8(SDA) ◄──I2C(跨弯曲区)──► MPU6050 SDA(p4)    │
ESP32-C3 GPIO9(SCL) ◄──I2C(跨弯曲区)──► MPU6050 SCL(p3)    │
ESP32-C3 GPIO10 ──360Ω──绿LED──GND（程序闪烁）              │
ESP32-C3 GPIO5  ──360Ω──黄LED──GND（预留控制）              │
ESP32-C3 GPIO21(TX)/GPIO20(RX) ──► 4pin 接口 TXD/RXD（TTL 3.3V）
MPU6050 AD0(p5) ──► GND（I2C 地址 0x68）
烧录：模块板载 USB Type-C（禁布区让开）
```

## 源—末端连线清单（逐根拉直，分叉即分化）

上图是"网络式"画法：5V 轨被四个器件共用，画成一坨。下面改写成"网表式"——**每一行是一条从头到尾的独立连线，中途每多出一条通路就向下分化一条路线**。读法与布线时一致：根 = 源，每个叶 = 末端，根到叶的一条链就是铜皮上要走的那一根线。

### 一、电源通路

```
① 4pin大焊盘① VIN(12V)
│
└─► 滑动开关 SK-3245S-L1-A（卧贴两档，动端进、常开端出）
    │
    └─► AMS1117-ADJ VIN（p3，SOT-223 铜箔）
        │
        │  ├─► CIN 10µF  ──► GND轨      （LDO 输入去耦，就近打）
        │  └─► R1 120Ω ──┐              （Vout→ADJ 支路）
        │                └─► Cadj 10µF ──► GND轨
        │
        ├─► [分叉] Vout(5.02V) 输出端 → 5V 轨，以下四条各自一条路线
        │
        ├──② 5V轨 ──► Cout 22µF  ──► GND轨       （LDO 输出储能）
        ├──③ 5V轨 ──► 0.1µF 高频去耦 ──► GND轨   （主体区）
        ├──④ 5V轨 ──► 红LED(0805) ──► R 360Ω ──► GND轨   （电源指示，常亮 ~8mA）
        │
        ├──⑤ 5V轨 ──► ESP32-C3 模块 5V 邮票孔 p1
        │             └─► 模块板载 LDO ──► 3.3V（模块内部，不出板）
        │
        └──⑥ 5V轨 ──► ESP32 模块 3.3V 脚 ─══穿越弯曲避让区 20mil══► MPU6050 模块 VCC(p1)   ★跨区 1/2
                      │
                      └─► 0.1µF 去耦 ──► GND轨   （窄条端，紧贴 VCC）
        ★ 供电取 3.3V 而非 5V 的原因：模块板载 5.1K 上拉跟随 VCC——若 VCC=5V，
          SDA/SCL 空闲电平为 5V，超出 ESP32-C3 IO 耐压（3.6V），长期损伤 IO 口；
          改由 ESP32 模块 3.3V 脚供电，上拉电平=3.3V，安全。MPU 模块板载 LDO
          压差仅约 0.1V，3.3V 输入时输出 ≈3.2V，仍在 MPU6050 2.375~3.46V 工作区间。

⑦ 滑动开关 另一端（GND 端）──► GND轨
⑧ 4pin大焊盘② GND ──► GND轨（全板共地）
```

### 二、I2C 总线（双向，两根线各写两个方向）

```
⑨ ESP32-C3 GPIO8(SDA) ══穿越弯曲避让区 20mil══► MPU6050 SDA(p4)   ★跨区 3
⑩ ESP32-C3 GPIO9(SCL) ══穿越弯曲避让区 20mil══► MPU6050 SCL(p3)   ★跨区 4

⑪ MPU6050 SDA(p4) ══穿越弯曲避让区══► ESP32-C3 GPIO8(SDA)        （⑨的反向，同一条铜皮）
⑫ MPU6050 SCL(p3) ══穿越弯曲避让区══► ESP32-C3 GPIO9(SCL)        （⑩的反向，同一条铜皮）
⑬ SDA/SCL 上拉 = MPU6050 模块板载 5.1K，上拉电平跟随 VCC（=3.3V，见⑥说明，不占清单元件）
⑭ MPU6050 AD0(p5) ──► GND轨   （决定 I2C 地址 0x68）
⑮ MPU6050 INT(p8) / AUX_CL(p6) / AUX_DA(p7) ──► 悬空（本方案不用）
```

### 三、UART / 对外接口

```
⑯ ESP32-C3 GPIO21(TX) ──► 4pin大焊盘③ TXD ──► 杜邦线 ──► 测试平台（3.3V TTL，MCU 发）
⑰ 测试平台 ──► 杜邦线 ──► 4pin大焊盘④ RXD ──► ESP32-C3 GPIO20(RX)（3.3V TTL，MCU 收）
⑱ ESP32-C3 模块板载 USB Type-C ──► 烧录/串口（禁布区让开，不走板内）
```

### 四、指示与预留（全部在主体区，不跨区）

```
⑲ ESP32-C3 GPIO10 ──► R 360Ω ──► 绿LED ──► GND轨   （程序闪烁，心跳）
⑳ ESP32-C3 GPIO5  ──► R 360Ω ──► 黄LED ──► GND轨   （预留控制）
```

### 跨区计数（红线自检）

| 跨弯曲避让区的线 | 来源路径号 | 数量 |
|---|---|---|
| 3.3V（MPU VCC） | ⑥ | 1 |
| GND（MPU 模块 p2 回流） | ⑧的延伸 | 1 |
| SDA | ⑨⑪ | 1 |
| SCL | ⑩⑫ | 1 |
| **合计** | | **4** |

> 结论：原框图只画了 I2C 两根跨区线，把供电线漏了；补齐 5V/GND 后正好 **4 根**，与 04 文档"跨弯曲区只走 4 根线"的要求吻合。三颗 LED 一律放主体区、紧邻 ESP32 引脚，**不得放窄条**——否则每多一根跨区线就多一条分化路线，直接踩规则③（弯曲区只允许走线+过孔）与 04 的 4 线上限。
