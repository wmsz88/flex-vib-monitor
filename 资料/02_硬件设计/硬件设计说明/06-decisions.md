# 06 决策门 — 已确定 / 待确认 / 高风险

**日期**：2026-09-20

## ✅ 已确定（可进入原理图绘制）

1. 主控/传感器/电源芯片 = 组委会指定器件，封装用组委会库
2. 稳压方案：AMS1117-ADJ，R1=120Ω / R2=360Ω，Vout≈5.02V，ADJ 旁路 10µF
3. 引脚分配：GPIO8=SDA、GPIO9=SCL、GPIO10=绿LED、GPIO5=黄LED、GPIO21/20=TXD/RXD
4. MPU6050 置于窄条紧贴弯曲区，跨区仅 4 线（5V/GND/SDA/SCL）
5. 双面板 + Gerber RS-274X 四件套
6. strapping 引脚核查：GPIO2 未使用 ✓；GPIO8（strapping，需高电平启动）被 MPU6050 模块板载 5.1K 上拉至 3.3V ✓；GPIO9=BOOT（模块板载按键+上拉，组委会模块本身如此设计）✓——不影响正常启动
7. **I2C 实现方式：用硬件 I2C（Wire 库），不用软件 I2C**（2026-10-01 定）。依据：ESP32-C3 内核 `variants/esp32c3/pins_arduino.h` 第 19/20 行 `SDA = 8`、`SCL = 9`——**本项目引脚恰好就是硬件 I2C 默认引脚**，`Wire.begin()` 零配置即正确；200kHz 下 1kHz 采样 × 7 字节 ≈ 72kbit/s，总线余量充足且 CPU 不空转；软件 I2C 在 ESP32 上稳定上限约 100kHz，1kHz 采样要吃掉约 2/3 的 CPU 周期，会挤压串口输出与包络计算。C3 只有 1 个 I2C 控制器——本项目 MPU6050 独占该总线，无需第二组，故无软件 I2C 的适用场景
8. **检测逻辑：两项指标同时输出，不切换采样率；不引入 PID**（2026-10-01 定）
   - 命题五节原文：需检测「**持续振动频率 80~180Hz**」与「**启停频率 0~3Hz**（某固定频率振动状态与无振动状态组成的周期频率）」。二者是**载波 / 包络**关系，**不是二选一**。
   - **逻辑上是串联依赖**：要算启停频率，必须先有「有振动 / 无振动」的判据；该判据来自 80~180Hz 那一路的能量（包络）经阈值判决。故两路共用同一条信号链，**不切换、不分时**。
   - **一个采样率吃两项**：1kHz 对 180Hz 载波是 5.5× 奈奎斯特余量，对 3Hz 包络余量 300×+。采样率无需切换；关键是 **DLPF 不能设窄**（DLPF_CFG=0 → 260Hz；设成几 Hz 会把 80~180Hz 直接滤没），并用高通（≥70Hz）去掉重力直流与低频漂移。
   - **不上 PID**：本模块是**检测/测量**设备，单向串口输出给外部平台，无执行器、无被控量、无设定值跟踪——PID 是闭环控制工具，此处无适用对象。幅度自适应应走**自适应阈值**（噪声底滑动平均 × 倍率），属统计方法而非 PID。唯一变数：第二环节任务现场发布，若临时包含控制要求再另行评估，但硬件上可控执行器仅三只 LED，不存在可 PID 的连续被控量。
