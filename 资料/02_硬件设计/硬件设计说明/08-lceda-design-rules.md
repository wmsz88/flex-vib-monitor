## 〇、三个从封装库里量出来的事实（先看，决定规则怎么配）

| # | 实测结果 | 对规则配置的影响 |
|---|---|---|
| 1 | **全库 16 个封装，`hole` 字段全部为 `null` —— 一处通孔焊盘都没有** | BOM 里没有插件件。整块板只会有一种孔：**过孔**。命题里的"插件焊盘 47/90mil""固定孔 118mil"对本设计是空条目——**不要建、不要放** |

## 一、先把外框尺寸链定对（命题图4 实测像素比）

图4 是**按比例绘制**的：55.0mm 与 35.0mm 两条尺寸线的比例尺一致（均 ≈14.7 px/mm），90.0mm 也对得上。据此读数：

```
        ├─────────────────── 90.0mm ────────────────────┤
        ├──────── 55.0mm ────────┼─────── 35.0mm ────────┤
   ┌─────────────────────────────┐
   │                             │ ┌────────────┐
22.3│      主体区 55.0 × 22.3      │ │弯曲 15.2×12.6│  窄条余量
   │      （器件全放这里）          │ │ 只许走线+过孔 │  19.8 × 12.6
   └─────────────────────────────┘ └────────────┘
                                   ↑             ↑
                                55.0mm       70.2mm
```

- **总长 90.0mm = 55.0 + 35.0**；100×25mm 是**上限**，不是目标尺寸
- 左段 55.0mm 长、高 22.3mm；右段 35.0mm 长、高 12.6mm
- **弯曲避让区 15.2mm 是"嵌在右段 35.0mm 里的头 15.2mm"，不是独立的第三段**
- ⚠️ 01 / 02 / 04 / 三人任务分工 四份文档原先写的 "55 + 15.2 + 35 = 总长90" 是**把 35 误当成了额外一段**（那样加起来是 105.2mm，直接超 100mm 上限）。本次已同步更正

**去掉避让区后，真正能放器件的净空间**：

| 区 | 净尺寸 | 放什么 |
|---|---|---|
| 主体区 | 55.0 × 22.3mm | ESP32-C3 模块（封装包围盒 20.67×19.31）、AMS1117、开关、3×LED+电阻、4pin 焊盘 |
| 弯曲避让区 | 15.2 × 12.6mm | **只走线 + 过孔**，禁一切器件 |
| 窄条余量 | **19.8 × 12.6mm** | MPU6050 模块（封装包围盒 **18.67 × 9.14**） |

⚠️ **窄条只剩 19.8mm 长**，而 MPU6050 封装横向就占 18.67mm —— **左右合计只剩 1.13mm 余量**（每边 0.57mm，刚刚够"与板框 ≥12mil = 0.305mm"）。这是全板最紧的一处：布局时 MPU 必须**紧贴弯曲区边缘**摆，不能再留手工余量。

## 三、设计规则逐项配置

打开 **设计 → 设计规则...**，按下面逐项填。

### 3.1 安全间距（Clearance）

命题要求：最小线间距（线边缘间距）10mil；导线-焊盘/导线-过孔/焊盘-焊盘/过孔-过孔/焊盘-过孔 ≥10mil；与边框 ≥12mil。

| 规则 | 作用对象 | 值 |
|---|---|---|
| `全局-10mil` | **全部**（所有对象两两） | **0.254mm (10mil)** |
| `边框-12mil` | **板框**（单独覆盖） | **0.305mm (12mil)** |

操作要点：安全间距在专业版里是**矩阵式**（行 = 对象A，列 = 对象B）。先把**所有格子**填 10mil，再把**「板框」所在的行与列**单独填 12mil。
铺铜相关行列可留着不动——因为本设计**不许铺铜**（§3.6），永远不会有对象跟铜皮比间距。

### 3.2 线宽（Track Width）

| 项 | 值 | 说明 |
|---|---|---|
| 最小线宽 | **0.254mm (10mil)** | 命题下限，DRC 靠这条拦 |
| 最大线宽 | **2.54mm (100mil)** | 命题上限 |
| 推荐 / 默认线宽 | **0.381mm (15mil)** | 手工布线默认值 |

分网络的实际取值见 §四（网络类）。

### 3.3 过孔（Via）

**这是最容易踩雷的一项**：软件自带的默认过孔类型（0.3/0.6、0.45/0.9 之类）尺寸五花八门，而命题写的是"其他尺寸/形状的过孔一概不予制作"。所以：

| 项 | 值 |
|---|---|
| 保留的过孔类型 | **只留 1 种**，命名 `Via-25-45` |
| 孔径（内径 / 钻孔） | **0.635mm (25mil)** |
| 直径（外径 / 焊盘） | **1.2mm (47mil)** —— 命题要求 ≥45mil(1.143mm)，取 1.2mm 圆整值，也可直接填 1.143mm |
| 类型 | 通孔（双面板只能通孔，不要盲埋孔） |
| 盖油 / 阻焊覆盖 | **盖油** |
| 其余所有自带过孔类型 | **删除或禁用** |

> 布完线后回来看一眼：`设计 → 过孔` 列表里应当**只有 `Via-25-45` 一个条目**。

### 3.4 孔（Hole）

| 项 | 值 |
|---|---|
| 允许的钻孔尺寸 | **只有 0.635mm 一种**（就是过孔） |
| 插件焊盘（通孔） | **不使用** —— 见 §0-1，全库无通孔焊盘，BOM 也无插件件 |
| 固定孔 3mm | **不放** —— 模块靠结构件/胶贴合手指，命题未要求，多一个孔多一条被挑的理由 |

软件里若预置了 0.3 / 0.4 / 0.8mm 等钻孔尺寸，**一并删除**。

### 3.5 器件（布局间距）

| 项 | 值 |
|---|---|
| 器件 ↔ 器件 | **0.508mm (20mil)** —— 命题"元器件最小间距 20mil" |
| 器件 ↔ 板框 | **0.5mm**（比 12mil 厚一点，柔性板边缘易崩） |
| 器件 ↔ 器件（同封装内） | 不适用（封装内不算器件间距） |

### 3.6 铺铜（Copper Pour）

命题：**禁止一切铺铜（Poly），全部以走线连通**，否则不予制作。

- **不创建任何铺铜**；若有"自动铺铜 / 自动补泪滴生成铜皮"之类的开关，**全部关闭**
- 专业版里还有个"铺铜"设计规则分类，**留着默认值不管即可**——只要不放铺铜，规则永远不触发
- 地网用**粗走线**（30mil 主干 + 分支）代替大面积铺铜

### 3.7 丝印（Silkscreen）

| 项 | 值 |
|---|---|
| 最小丝印线宽 | **0.15mm (6mil)**（嘉立创工艺下限） |
| 丝印 ↔ 阻焊 / 焊盘间距 | **≥0.15mm (6mil)** |
| 位号文字高度 | **≥0.8mm** |
| 丝印压焊盘 | **禁止** |

必须有的丝印标记：**4pin 的 ①VIN / ②GND / ③TXD / ④RXD 顺序标号**（现场焊线全靠它）、三颗 LED 的极性标记、AMS1117 的 1/2/3/TAB 脚位。

### 3.8 阻焊（Solder Mask）★ 关键

| 项 | 值 | 为什么 |
|---|---|---|
| **阻焊扩展（开窗扩展）** | **0.10mm (4mil)** | ⚠️ **必须 > 0**。见 §0-2：4pin 焊盘铜皮正好 4.00×2.00mm，扩展 0.10mm 后开窗为 4.10×2.10mm（按单边算）或 4.20×2.20mm（按双边算），**两种算法都满足"开窗 > 4mm×2mm"** |
| 阻焊桥最小宽度 | **≥0.10mm (4mil)** | 0805 内间距 0.62mm，绰绰有余 |
| 过孔 | **盖油** | |
| 开窗 | 除 4pin 与焊盘外**不做任何额外开窗** | |

> **导出 Gerber 后必须实测**：打开 `GTS`（顶层阻焊）文件，量一下 4 个 4pin 开窗的实际尺寸，确认每个都 **>4mm × 2mm**。这是命题白纸黑字"每个焊盘开窗尺寸大于 4mm×2mm"，是评委最容易拿卡尺量的一条。

### 3.9 差分对 / 等长（不用配）

I²C 400kHz、UART 115200 —— 不需要差分对、不需要等长、不需要阻抗控制。**保持默认，不新建任何规则。**

## 四、网络类（Net Class）

在 `设计规则 → 网络类` 里建两个类，把网络归进去。

| 网络类 | 包含网络 | 线宽 | 间距 | 过孔 |
|---|---|---|---|---|
| `POWER` | `VIN`(12V)、`+5V`、`+3V3`（MPU_VCC）、`GND` | **0.762mm (30mil)** | 0.254mm | `Via-25-45` |
| `SIGNAL` | `SDA`、`SCL`、`TXD`、`RXD`、绿/黄/红 LED 驱动 | **0.305mm (12mil)** | 0.254mm | `Via-25-45` |

> 电流校核：整机约 75mA 典型 / 350mA 峰值。10mil 走线在 1oz 铜上就跑得动，30mil 是给柔性板（压延铜通常更薄）和内阻留的余量。
>
> 网络名以**你改完原理图后重新导出的网表**为准；当前网表里还残留 `$1N14` 之类的自动名，重新导出后应改成语义化名字再归类。

## 五、约束区域（弯曲避让区，15.2 × 12.6mm）

`放置 → 约束区域`，框住中段 15.2mm，然后给它挂一套更严的规则：

| 项 | 全局值 | 弯曲区内 | 理由 |
|---|---|---|---|
| 安全间距 | 10mil | **15mil (0.381mm)** | 弯曲区走线偏移风险更大，留更多余量 |
| 线宽范围 | 10~100mil | **10~12mil (0.254~0.305mm)** | 柔性区**细线比粗线抗弯折**——宽铜皮反复弯曲时更容易沿晶界开裂 |

**这是加分项，不是必须项。** 但它让方案文档里能写出"我们专门为柔性弯曲区做了可靠性设计"，评审看"设计合理性"时有据可依。写进方案文档。

## 六、禁止区域（两处，用途不同）

### 6.1 中段弯曲避让区（15.2mm）

`放置 → 禁止区域`，画在中段。

**勾选项**（专业版的禁止区域各项是独立勾选的）：

| 勾选项 | 勾不勾 | 理由 |
|---|---|---|
| 禁止放置器件 | ✅ **勾** | 命题"该区域内严禁放置任何元器件" |
| 禁止放置焊盘 | ✅ **勾** | 焊盘=器件 |
| 禁止走线 | ❌ **不勾** | 命题明确"只允许进行电气布线与过孔" |
| 禁止放置过孔 | ❌ **不勾** | 同上 |
| 禁止铺铜 | 无所谓 | 全板本来就不铺铜 |

> **⚠️ 图层绝不要选 GKO（Keep-Out / 板框层）。**
> 命题："除边框外，Keep-Out Layer 不能有其他任何图案"。把禁止区域画到 GKO 上 = GKO 层多出图案 = **不予制作**。
> 禁止区域应属于**独立的禁止区域对象**（不归属板框层）。若你的版本会把禁止区域渲染进 GKO，**就干脆不画这个区域**——人工保证器件不越界即可，宁可少一层自动检查，也不要赌 GKO 的干净。
> **导 Gerber 后务必打开 `GKO` 文件确认：里面只有那一个闭合外框。**

### 6.2 ESP32 模块 Type-C 投影区（命题图7）

模块背面 Type-C 连接器两侧对应区域**禁止布线**，防止连接器金属壳与板上铜皮短接。

| 勾选项 | 勾不勾 |
|---|---|
| 禁止走线 | ✅ **勾** |
| 禁止放置过孔 | ✅ **勾** |
| 禁止放置器件 / 焊盘 | ✅ **勾** |

这处**是允许禁走线的**，与 6.1 相反，别混。

## 七、板框（Board Outline）

| 项 | 值 |
|---|---|
| 图层 | **Keep-Out Layer (GKO)**，且**只有它** |
| 图案数 | **有且只有 1 个** |
| 闭合性 | 必须**闭合**，无断点 |
| 线宽 | **全部线条统一**（建议 10mil / 0.254mm），不能有粗有细 |
| 尺寸 | 见 §一：总长 90.0mm，左段 55.0×22.3，右段 35.0×12.6（含头 15.2mm 避让区） |
| 上限 | ≤100 × 25mm |

台阶矩形（左高右低）画法：从左上角起→右下→阶梯→回到起点，一笔闭合。**不要用两个矩形叠**。

## 八、DRC 查不到、必须人工核对的 6 条

嘉立创专业版的 DRC 只能查间距/线宽/孔径这类几何量。下面这些**它管不了**，出 Gerber 前逐条打勾：

| # | 要核对的 | 怎么查 |
|---|---|---|
| 1 | **GKO 层只有 1 个闭合外框，无其他图案** | 单独打开 GKO 文件看 |
| 2 | **全板无任何铺铜（Poly）** | 逐层看，或用"对象列表"筛 Poly |
| 3 | **外形 ≤100×25mm** | 量板框包围盒 |
| 4 | **4pin 开窗每个 > 4mm×2mm** | 量 GTS 层实际开窗 |
| 5 | **过孔只有 25/45mil 一种** | 看设计规则的过孔列表 |
| 6 | **弯曲区无器件** | 目视 + 对象列表 |

**灰区风险（写下来备查，不一定要改）**：
- 开关 `SW-SMD_SK-3245S-L1-A-1` 引脚间距 **2.50mm (98.42mil)** < "板载连接器 ≥100mil"。开关**不是连接器**，字面上不适用这条；而且这是组委会自己的封装库。但评委若较真，需要能解释——**建议在方案文档里写明"开关按组委会封装库直接调用"**，把责任归位到库。
- 4pin 焊盘（`2PIN贴片线焊盘`）的 4 个焊盘横向有 1.5mil（0.04mm）的错位（两个在 x=90.00，两个在 x=91.53）。肉眼不可见，不影响焊接，但如果你自己重画，对齐一下更好。

## 附：和 04 文档的关系

`04-constraints.md` 是**命题原文的规则清单**（给人和评委看的）；本文档是**同一批规则在嘉立创EDA专业版里的落地配置**（给手用的）。两份不矛盾，04 是"要求什么"，08 是"软件里填什么"。改规则时两边都要动。
