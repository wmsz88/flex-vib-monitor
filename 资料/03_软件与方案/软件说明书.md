## 2. 软件模块

### 2.1 `mpu.cpp`

负责 MPU6050 初始化、量程配置和原始数据读取。

- 加速度量程 ±2g
- 陀螺量程 ±500 dps
- I2C 读取失败会计数，用于状态页判断硬件可靠性

### 2.2 `sampler.cpp`

负责 1 kHz 定时采样与样本队列。

主要作用：

1. 从 MPU6050 读原始加速度、陀螺数据
2. 记录时间戳和采样缺口
3. 统计 I2C 错误、读失败、ring 水位
4. 给 DSP 提供稳定的数据流

现场判断：`S` / `T` 页面中 `I2C错`、`读失败`、`不连续` 应为 0。

### 2.3 `dsp.cpp`

把原始加速度变成三个量：

1. **主频 F**
2. **幅值 A**
3. **持续振动状态 VIB**

处理过程：

```text
原始加速度
  ↓ 去基线
  ↓ 高通滤波
  ↓ 过零点检测
  ↓ 周期中位数
  → 主频 F

滤波后信号
  ↓ RMS / 包络
  → 幅值 A
```

关键参数：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `FREQ_LO_HZ` | 60 | 主频有效下限 |
| `FREQ_HI_HZ` | 220 | 主频有效上限 |
| `SS_HI_MG` | 120 | 启停起振高门 |
| `SS_LO_MG` | 80 | 启停保持低门 |

### 2.4 `posture.cpp`

负责姿态分类和 START 基线。

两类姿态：

- `START`：张开
- `HONGEST`：闭合

`P` 命令会重采 START 基线。若闭合角无效、当前角度过大或姿态偏差过大，固件会拒绝，避免把错误姿态写成基准。

### 2.5 `state.cpp`

最终版的核心接触逻辑。

**接触三条：**

1. **进入接触**
   - 闭合角达到阈值
   - 手指已停下
   - 有振动证据
2. **保持接触**
   - 不再看加速度
   - 没有超时退出
3. **分离**
   - 手指张开
   - 或接触后净转角超过 10°

关键参数：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `CT_V6_ENABLE` | 1 | 打开 V6 接触逻辑 |
| `CT_SETTLE_ENABLE` | 1 | 要求手指停下 |
| `CT_SETTLE_DPS` | 10 | 低通角速度静止门限 |
| `CT_SETTLE_MS` | 150 | 停下确认时间 |
| `CT_RELEASE_DEG` | 10 | 接触后再转过此角度算分离 |
| `GYRO_LP_HZ` | 4 | 陀螺低通截止 |
| `CT_RELEASE_NET` | 1 | 使用净转角判分离 |
| `CT_RELEASE_TAU_MS` | 500 | 净转角泄漏时间 |

**重要语义：**

- 振动停止但手指仍夹住时，`ct` 可以保持 1。
- 松手后 `ct` 会退出，实测延迟约 20~396 ms。
- 无振动夹物 / 空握不应进入接触。

### 2.6 `output.cpp`

负责调试输出、比赛帧、串口命令和 LED。

比赛帧格式：

```text
$VD,SEQ,FREQx10,AMP_MG,VIB,CT,SSx100,VALID,CHK\r\n
```

示例：

```text
$VD,0137,01652,00966,1,1,120,F,63
```

字段：

| 字段 | 含义 |
|---|---|
| `$VD` | 帧头 |
| `SEQ` | 4 位帧序号 |
| `FREQx10` | 主频 ×10，1652 表示 165.2 Hz |
| `AMP_MG` | 幅值 mg |
| `VIB` | 持续振动，0/1 |
| `CT` | 接触，0/1 |
| `SSx100` | 启停频率 ×100，120 表示 1.20 Hz |
| `VALID` | 有效性位图 |
| `CHK` | 正文 XOR 校验，两位十六进制 |

## 3. 串口命令

调试口命令均为单字符或两字符。

| 命令 | 作用 |
|:--:|---|
| `?` | 帮助 |
| `0`~`4` | 绘图组：0 关、1 结果、2 启停、3 接触、4 波形 |
| `p` | 轮换绘图组 |
| `d` | 开关调试行 |
| `S` | 完整状态页 |
| `T` | 采样与耗时统计 |
| `w` | 输出一行 `#SWEEP` |
| `Q` | 输出一行 `#POST` |
| `P` | 重采 START 姿态基线 |
| `c` | 重新标定，要求静置 |
| `t` | 采集平放基准 |
| `t0` | 清除平放基准 |
| `x` | 清零统计 |
| `D` | 全量状态 CSV |
| `k0`~`k6` | 打标模式 |
| `K` | 退出打标模式 |

V6 中按 `d` 后会额外输出：

```text
#V6 closed= ang= lpW= settled= moved=
```

含义：

| 字段 | 含义 |
|---|---|
| `closed` | 是否闭合 |
| `ang` | 闭合角 |
| `lpW` | 低通后合成角速度 |
| `settled` | 手指是否已停下 |
| `moved` | 接触后净转角 |

## 4. 标准操作流程

### 4.1 上电

```text
1. 模块上电 / 复位前保持 START 张开姿态
2. 等待标定完成
3. 确认红灯常亮、绿灯 1Hz 心跳
4. 打开调试口，波特率 115200
```

### 4.2 采 START 基线

```text
1. 保持 START 姿态静止
2. 发 P
3. 等 2 秒
4. 发 Q，确认 cal=1、cls=START、d≈0
```

### 4.3 空握负对照

```text
1. 不放物体，收拢手指
2. 停 2~3 秒
3. 发 w 或 S
4. 预期：closed=1，ct=0
```

### 4.4 接触测试

```text
1. 夹住振动测试件
2. 开启振源
3. 手指停下
4. 等待 2~3 秒
5. 发 w 或 S
6. 预期：closed=1，vib=1，ct=1
```

### 4.5 分离测试

```text
1. 保持接触状态
2. 松手或张开
3. 预期 ct 变 0
4. 回到 START 并停 2 秒
5. 预期 closed=0
```

## 5. 现场修改

### 5.1 原则

1. 先看 `现场适配预案手册_20261106.md`
2. 不要直接改 `state.cpp` 判据链
3. 优先改 `config.h` 宏
4. 改完必须编译 + 宿主测试 + 实板验证

### 5.2 常用可改项

| 情况 | 修改 |
|---|---|
| 手指停下判断太严 | `CT_SETTLE_ENABLE=0` 或放宽 `CT_SETTLE_DPS` |
| 分离太灵敏 | 增大 `CT_RELEASE_DEG` |
| 分离太钝 | 减小 `CT_RELEASE_DEG` |
| 姿态基准错误 | 回 START，按 `P` 重采 |
| 平台要求闭合字段 | 参考 v7 的 `COMP_FRAME_CL=1` |
| 平台只认 CSV | 参考 v7 的 `COMP_FRAME_CSV=1` |
| 平台嫌 50Hz 太快 | 参考 v7 的分频宏 |

### 5.3 编译

arduino-cli 的 build path 不能含中文，推荐流程：

```text
1. 复制 vibmon_v6 的 .ino/.h/.cpp 到英文临时目录
2. 文件夹名保持 vibmon_v6
3. 编译
4. 产物拷回预编译目录
```

命令：

```bash
arduino-cli compile --fqbn esp32:esp32:esp32c3 --warnings all "<英文临时目录>/vibmon_v6"
```

CDC 构建：

```bash
arduino-cli compile --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --warnings all "<英文临时目录>/vibmon_v6"
```

## 6. 答辩一句话

**这套软件用 MPU6050 同时读取加速度和陀螺仪：加速度负责测振动主频、幅值和启停频率；陀螺仪负责判断手指闭合、停下、分离。V6 的核心改进是把接触状态从“靠振动维持”改为“接触后由陀螺姿态维持”，因此能区分真正接触与无振动夹持。**
