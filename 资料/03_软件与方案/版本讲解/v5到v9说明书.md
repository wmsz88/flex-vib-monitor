## 3. 软件模块（五版共用骨架，v6 结构）

数据流（答辩必背）：

```text
mpu（I2C 读 MPU6050，1kHz）→ sampler（定时采样/缺口/统计）→ dsp（去基线 → 高通70Hz
→ 过零测频 F / RMS 包络 A / 启停状态 SS）→ posture（START 基线与开合角）→ state（接触状态机）
→ output（比赛口 $VD 50Hz + 调试口命令/绘图/LED）
```

| 模块 | 职责 | 关键点 |
|---|---|---|
| `mpu.cpp` | MPU6050 初始化与原始读取 | 加速度 ±4g、陀螺 ±500dps、I2C 200kHz、错误计数 |
| `sampler.cpp` | 1kHz 定时采样、环形队列、缺口检测 | `RING_N=512`；缺口插值保护；`I2C错/读失败/不连续` 应为 0 |
| `dsp.cpp` | 测频（过零 F）、幅值（RMS 包络 A）、启停（SS 状态机） | 高通 70Hz 保住 80~180Hz 命题段；主频刷新 15.6Hz、包络 100Hz |
| `posture.cpp` | START 姿态基线与开合角（陀螺积分） | 上电/复位必须 START 姿态，否则角度恒 0、判据失效 |
| `state.cpp` | 接触状态机、启停节奏、平放基准、分层喂数（v8） | 各版本差异集中地（见 §4） |
| `output.cpp` | `$VD` 帧、调试命令、绘图、LED、黄绿灯语义 | 各版本差异集中地（见 §4） |
| `config.h` | 全部参数宏 + 编译期断言 | 《可调参数总表》150 条分七类 |

## 4. 各版本差异（改了什么，细节见逐行讲解）

### v6 相对 v5：接触判据反转（T012）

只动 `config.h` / `state.cpp`(+138) / `state.h`(+3 字段) / `output.cpp`(+5 行 `#V6`)：

- **接触三条**：进入 = 收拢 + 手指已停（两级 4Hz 低通后 <10dps 持 150ms）+ 振动证据（幅值且频率，或启停 ≥1.5Hz）；保持 = 不看加速度，只有陀螺能退出；分离 = 张开或净转角 >10°（500ms 泄漏积分，来回摆抵消）。
- 启停门 `SS_HI/LO` 180/150 → 120/80（旧振子 3Hz 读数 0%→59%）。
- 收拢后首停清启停历史；接触中启停取最新一致段。
- 保持语义：关源后手不动 CT=1 是**有意设计**（T013 实测 16.4s 保持）。

### v7 相对 v6：只动输出侧（T010）

只动 `config.h` / `output.cpp`，判据链五文件逐字节相同：

1. 黄灯改接触联动（CT=1 时 2Hz 闪）+ `y` 三态 AUTO/ON/OFF；
2. 三预案宏：`COMP_FRAME_CSV`（0/1 文本行）、`COMP_FRAME_DIV`（1/2/5 分频）、`COMP_FRAME_GATED`（收 `S` 发 `X` 停）——默认全关，出发字节流零变化；
3. 7 个预编译变体：def / cl / csv / div2 / gate / v5sem（`CT_V6_ENABLE=0` 回 v5 语义）/ uart（非 CDC）。

### v8 相对 v6：分层检测实验（T014）

新增模块 `layered_detection.h/.cpp`（v8 独有）：

- 实时层：滞回 + 3 点确认的分层振动/接触标志；均匀层：50 点滑窗中位数、P90-P10 离散度、有效率、`stable` 判据。
- 接线两处：`state.cpp` 每包络点 `layerPush()`（旁挂喂数，不动判据）；`output.cpp` `debugLine()` 加 `#LAYER` 行（只打印）。
- `config.h` 加 9 个 `LAYER_*` 宏；`LAYERED_DETECT_ENABLE=0` 完整回 V6（`v6_fallback` 89/89 证明）。
- v8 删掉了 v7 的黄灯三态/CSV/分频/门控与 `led_test`，`COMP_FRAME_ENABLED=0`。

### v9 相对 v6：平放基准时机实验

只动 `config.h` / `state.cpp`（output 与 v6 逐字节相同，`vibmon_v9.ino` 与 v6 内容相同）：

1. 新宏 `CT_REF_REOPEN_ONLY=1`（`config.h:552-554`）：自动重采平放基准在原三条件（静止 ≥2s、幅值 <100mg、角度 <8°）之外，**还要求角度确实回到张开区**（`state.cpp:855-858`，`|closeAngle| ≥ AUTO_ZERO_ANGLE_DEG(8°)` 才允许清基准重采）。防的坑：手一直握着只关振源时角度仍在闭合区，旧逻辑会把「握物姿态」当平放零点，下一轮接触判据全歪。
2. 新宏 `FLAT_REF_REZERO_ON_CLOSE=0`（`config.h:143-148`，默认关）：预留的「闭合状态也允许重采」开关，注释写明为什么默认禁止。
3. v9 **删掉了** v8 的分层检测件（无 `layered_detection.*`，无 `#LAYER`），`COMP_FRAME_ENABLED` 回 1。
4. 测试语料：`测试\V6C\`（2026-11-08 串口日志，v9 固件实采）。

## 5. 判据语义对照（答辩口径）

| 项 | v5 | v6（=v7/v8/v9 判据） |
|---|---|---|
| 进入接触 | 闭合 + 振动证据（加速度为主） | 闭合 + **手指已停** + 振动证据（陀螺先） |
| 保持接触 | 依赖振动证据/保持门 | 只看陀螺；振源关掉手不动仍保持 |
| 分离 | 振动/姿态证据退出 | 张开（角度门）或净转角 >10° |
| 关源后 | CT 0.30~0.42s 退出 | 手不动则保持（v5sem 变体可回 v5 行为） |

判据门限（v6 起）：幅值 400/300mg、频率 75/63Hz、闭合角 60/45°、启停进入 ≥1.5Hz、净转角分离 >10°。

## 6. 串口（比赛口 + 调试口）

比赛口（4pin：①TX=GPIO21 ②RX=GPIO20 ③GND ④VIN；115200 8N1；50Hz）：

- `$VD,SEQ,FREQx10,AMP_MG,VIB,CT,SSx100,VALID,CHK\r\n` = 35 字节；`COMP_FRAME_CL=1` 时 37 字节（CT 后插 CL）。帧纯 ASCII，任何编码环境直接解析。
- 平台只认 CSV / 嫌 50Hz 快 / 要命令触发 → v7 三预案宏或变体（细则见《其他改动要求》§6）。

调试口（USB-CDC，115200）命令表：

| 命令 | 作用 |
|---|---|
| `?` | 帮助 |
| `d` | 调试行：`#F=` 结果行 + `#V6 closed/ang/lpW/settled/moved`（v8 另有 `#LAYER`） |
| `y` | 黄灯三态 AUTO→ON→OFF（仅 v7） |
| `S` | 状态摘要 |
| `D` | 全量 CSV（看接触三路 condPosture/condAmp/condFreq） |
| `c` | 重标定（须静置） |
| `t` / `t0` | 采/清平放基准（v9 重采多一道张开判定） |
| `P` | 重采 START 姿态基线 |
| `w` | 波形抽取比（运行时调） |

## 8. 现场修改与回退（流程一步不跳）

流程：**改 → 编译（英文临时目录）→ 宿主测试 → 烧录 → 实板验证 → 记录**。

```text
arduino-cli compile --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --warnings all "<英文目录>\vibmon_v6"
arduino-cli upload  -p COMx --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --input-dir "<变体或build目录>"
```

回退决策表：

| 现场情况 | 动作 |
|---|---|
| 平台要输出适配（CSV/分频/门控/CL/黄灯） | 用 v7 或其变体 |
| 平台要求「不振动就掉 CT」 | v7 `v5sem` 变体 |
