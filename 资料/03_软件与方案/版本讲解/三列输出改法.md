# 三列输出改法（固定频率 / 启停 / 接触）

> 日期：2026-11-08
> 需求：平台到时候只要三个数——**固定频率（FREQ）、启停（SS）、接触（CT）**，其余列（AMP、VIB、SEQ、VALID、CHK）都不要。
> 本文给三种改法，按现场状况挑一种；行号均已对源码核对。

## 0. 三列的原始来源（先认清每个数是什么）

| 列 | 字段 | 来源 | 无效时发什么 |
|---|---|---|---|
| 固定频率 | FREQ（Hz） | 过零测频：振动主频，命题范围 80~180Hz，判据门限 60~220Hz（`config.h:220-224`） | `0`（`encFreqX10()` 见 `v6\output.cpp:85-90`，`!freqValid → 0`；FREQx10 上限 99999） |
| 启停 | SS（Hz，×100 定点） | 启停节奏状态机：0.5/1/2/3Hz 档 | `0`（`encSsX100()` 见 `v6\output.cpp:101-107`，`!ssValid → 0`；上限 999=9.99Hz） |
| 接触 | CT | 接触三条状态机 | 恒 0/1（bool，无"无效"概念） |

注意：`Result` 里的 `freqHz` 无效时本身就是 0（`state.cpp` 多处 `s_r.freqHz = 0`），`encFreqX10` 只是兜底；VIB 的判 1 门槛是幅值滞回 `TH_HI/TH_LO`（`config.h:248-251` 的 `TH_HI_K/TH_LO_K` = 静置包络 ×5/×2.5，下限 8/4mg）——与"平台要不要 AMP/VIB 列"无关，**只砍列不动判据，三列数值和完整版逐帧一致**。

## 1. 改法 A：定长 `$VD` 帧，只砍列（35→N 字节）

适用：平台仍按"帧头+定长"读，但只要这三列。**零新宏，改一处函数。**

改哪里：`代码\vibmon_v6\output.cpp:140-165` 的 `compBuildFrame()`，把 body 拼帧与字段行替换为：

```cpp
int compBuildFrame(const Result& r, uint16_t seq, char* out, int outSize) {
  if (!out || outSize < COMP_OUT_MIN) return -1;

  const unsigned fq = encFreqX10(r);   // 固定频率 ×10（80~180Hz → 800~1800，4 位）
  const unsigned ss = encSsX100(r);    // 启停 ×100，0~999
  const unsigned ct = (unsigned)(r.contact ? 1 : 0);
  (void)seq;                           // 三列帧不带 SEQ，显式吞参防告警

  char body[COMP_BODY_SIZE];
  const int n = snprintf(body, sizeof(body), "$VD,%03u,%03u,%u",
                         fq, ss, ct);
  if (n <= 0 || n >= (int)sizeof(body)) return -1;

  const uint8_t chk = xorChk(body, n);
  const int m = snprintf(out, (size_t)outSize, "%s,%02X\r\n", body, chk);
  if (m <= 0 || m >= outSize) return -1;
  return m;
}
```

说明：

- 帧样例（165.2Hz、SS=1.20Hz、接触中）：`$VD,165,120,1,3F\r\n` = 18 字节（`3F` 为异或校验示例值）。缓冲区沿用 `COMP_BODY_SIZE/COMP_OUT_MIN`（`output.cpp:132-138`，本帧更短不会溢出）。
- `seq` 参数不再使用，代码块里已加 `(void)seq;` 防告警（照抄 CSV 分支的做法，`v7\output.cpp:169`）。
- 帧长不再定长（FREQ 3~4 位）。平台要定长就改 `%03u` → `%04u` 补零到 4 位（FREQx10 上限 2200，4 位封顶）。
- 除非平台明确还要校验，`chk` 也可以整段删（`xorChk` 会变未使用函数，`-Wall` 会报——把它用 `#if 0` 包住或一并删掉）。

## 2. 改法 B：CSV 文本行，三列（推荐，平台只认文本时）

适用：平台按逗号分隔文本读。**在 v7 上只改一条格式串。**

改哪里：`代码\vibmon_v7\output.cpp:158-170` 的 CSV 分支，把

```cpp
const int mC = snprintf(out, (size_t)outSize, "%u,%u,%.1f,%u,%.2f\r\n",   // 原 5 列见 v7\output.cpp:165-167
                        (unsigned)(r.contact ? 1 : 0), (unsigned)(r.vib ? 1 : 0),
                        (double)fqC, (unsigned)(int)(amC + 0.5f), (double)ssC);
```

换成（列序 = 平台要的顺序）：

```cpp
const int mC = snprintf(out, (size_t)outSize, "%u,%.1f,%.2f\r\n",
                        (unsigned)(r.contact ? 1 : 0),
                        (double)fqC, (double)ssC);
```

说明：

- 输出样例：`1,165.2,1.20\r\n` = 14 字节；无接触时 `0,0.0,0.00`。频率在 CSV 里是 `%.1f` 实际 Hz（不是 ×10 定点）。
- `amC` 的防护行（`v7\output.cpp:163`）删掉后无人引用，`-Wall` 对未使用的 `const` 局部变量会告警——**连 `const float amC = ...;` 那行一起删**。
- 列序如果平台要「频率,启停,接触」，把格式串和实参一起调顺序即可，一行搞定。
- 前提：这是 V7 分支（宏 `COMP_FRAME_CSV=1`）。若现场在 V6 上改，先照《修改说明.md》§3 把 CSV 分支整体搬进 `compBuildFrame()`，再套用本节改法。

## 3. 改法 C：零代码——改用 `D` 命令全量行 + 平台侧过滤（应急）

适用：平台能收文本行但来不及重烧，或评委只看现象不看帧。

- 调试口（USB-CDC）发 `D`，模块回一行全量 CSV（含 FREQ、SS、CT），平台侧或人眼取三列即可。
- 局限：调试口是 USB 虚拟串口，**不是比赛 4pin 口**；帧率与触发不受门控宏控制。只作应急演示，不作正式对接。

## 4. 三种改法怎么选（现场决策）

| 现场情况 | 选 | 代价 |
|---|---|---|
| 平台按帧头/定长读，明确不要 AMP/VIB/SEQ/VALID | A（砍列） | 改 1 个函数，重烧 |
| 平台只认逗号分隔文本行 | B（v7 CSV 改格式串） | 改 1 行格式串，重烧 |
| 来不及烧 / 只做演示 | C（`D` 命令） | 零代码，但走 USB 口不是 4pin |

通用验收（三法一致）：

1. 编译 0 warning（英文临时目录，FQBN `esp32:esp32:esp32c3:CDCOnBoot=cdc`）。
2. 宿主 `comp_frame_test`：改法 A/B 改了帧定义，22 项断言按定义不再适用——预期失败，不是 bug（与 CSV 模式同理，见《现场修改实操记录_20261108.md》§四）。别的测试项必须与基线一致。
3. 实板核对三列数值与改前完整帧逐帧一致（只砍列不改判据）；数一秒帧数确认 50Hz 未变。
4. 记录：改动位置、帧长/格式样例、`SHA` 或提交号。

## 5. 一页速记

- 三列 = `encFreqX10(r)` + `encSsX100(r)` + `r.contact`，无效值照旧发 0，语义与完整帧相同。
- 改法 A：`v6\output.cpp:140-165`，`snprintf` 一行决定帧样貌；要定长补 `%04u`；删校验记得包 `xorChk`。
- 改法 B：`v7\output.cpp:165-167`，只换格式串与实参；列序随平台；需 `COMP_FRAME_CSV=1`。
- 改法 C：零代码应急，`D` 命令行取数，仅限调试口。
- 改完必做：0 warning 编译 + 实板三列比对 + 帧率核对 + 记录。
