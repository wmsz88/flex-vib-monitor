## 0. 总纪律（先背这段）

1. **先改宏，再改代码**：`config.h` 宏是首选（风险最低）→ `output.cpp` 次之 → **绝不临时改 `state.cpp` 判据链**。
2. **默认行为必须不变**：新功能一律 `#if` / `#ifndef` 门控，默认值 = V6 行为。
3. **改前确认版本**：改的是 `01_出发固件\01_最终版v6\源码`（或其副本）；V6 原样归档不直接改。
4. **每改一个功能完整验证**：编译 0 warning → 宿主测试 → 实板 `$VD` 帧不变 → I2C 统计无异常。
5. **编译路径不能含中文**：先把源码拷到英文临时目录（文件夹名保持 `vibmon_v6`），2026-11-08 实操再次踩实。
6. **七不**：不现场重构、不删功能、不改文件名、不用中文路径编译、不把 V7 当最终版、每改先跑帧测试、无法验证的改动不烧板。

## 1. 串口 / 帧协议类（预案 #1~#5 的非判据部分）

### 1.1 波特率（预案 #2，实操 #7 已过）

- 位置：`config.h:34-36`（`COMP_BAUD`，`35` 行定义，默认 `115200`）。
- 作用：平台要 9600/4800 时改这一行重烧（9600 实测 Flash 373000B、0 warning、宿主与基线一致）。
- 配套：平台串口同步改 8N1；调试口 `BAUD` 不受影响；改后 `$VD` 帧应恢复可读。

### 1.2 CL 字段（预案 #1 情况 B，实操 #4 已过）

- 位置：`config.h:51`（`#define COMP_FRAME_CL 0`，默认 `0`）。
- 作用：改 `1` 后帧 35 → 37 字节，`CT` 后插 `CL`（闭合角状态）字段。
- 注意（实操实测）：`comp_frame_test` 会从 22 项变 25 项且全过，但 `run_all.ps1` 把期望写死 22 项会误判 FAIL——工具口径问题，不是功能问题。

### 1.3 静默（预案 #5 情况 B，实操 #8 已过）

- 位置：`config.h:37-39`（`COMP_FRAME_ENABLED`，`38` 行定义，默认 `1`）。
- 作用：改 `0` 后比赛口完全不发（发送函数编译为空，零开销），调试口照常。实测 Flash 省 1004B。

### 1.4 帧格式与编码（预案 #1 情况 A / #4）

- `$VD` 35 字节纯 ASCII：`$VD,SEQ,FREQx10,AMP_MG,VIB,CT,SSx100,VALID,CHK\r\n`，任何编码环境直接解析（答辩标准口径）。
- 帧率上限 50Hz（`COMP_PERIOD_MS=20`，`config.h:40-42`）：判据刷新受 DSP 包络窗约束，**做不到更快**，如实说明。

## 2. 检测判据 / 语义类（预案 #6~#8）

### 2.1 CT 持续语义（预案 #6）

- 平台查「夹着必须恒 1」→ 零改动：v6 保持语义下振源关掉也 CT=1（T013 实测关源 16.4s 仍为 1），**这是有意设计不是锁死 bug**。
- 平台要「不振动就快速掉 0」→ 烧 `v5sem` 变体（`-DCT_V6_ENABLE=0`，回 v5 关源 0.30~0.42s 退出语义）。

### 2.2 接触参数（预案 #7，实操 #5 已过；判据细节见 `v5到v6逐行讲解.md`）

位置全在 `config.h`，按现象小步调：

| 现象 | 宏（行号） | 方向 |
|---|---|---|
| 手指已停但不进接触 | `CT_SETTLE_DPS`（385-387） | 10 → 15 → 20 |
| 振动中一直判「未停下」 | `CT_SETTLE_ENABLE`（382-384） | 1 → 0 |
| 停下确认太慢 | `CT_SETTLE_MS`（388-390） | 150 → 100 |
| 接触后误分离 | `CT_RELEASE_DEG`（391-393） | 10 → 15 → 20 |
| 松手后退出太慢 | `CT_RELEASE_DEG` | 10 → 8 |
| 接触中误判滑动 | `CT_RELEASE_TAU_MS`（410-412） | 500 → 300 |
| 平台件幅值小 | `CT_FLAT_A_ON_MG / CT_FLAT_A_OFF_MG`（464-468，400/300） | 调低，OFF 比 ON 小 25% |
| 平台件频率低 | `CT_FLAT_F_ON_HZ / CT_FLAT_F_OFF_HZ`（482-483，75/63） | OFF 不得低于 60Hz（编译期断言拦） |

改后必须三项实测：空握不进、振动接触进、松手退出。

### 2.3 传感器量程（预案 #8）

- 位置：`config.h:59`（`#define ACCEL_FS_SEL 1`，默认 `1` = ±4g）。
- 冲击削顶（`clip` 计数涨 / 帧 `[clip]`）→ 改 `2`（±8g）重烧；信号弱 → 查贴装与夹持压力，**不动量程**（放大连噪声一起放大）。

## 3. LED 类（预案 #9~#11，赛题硬性要求）

### 3.1 绿灯 GPIO10（1Hz 心跳 = 电路正常运行）

- 位置：引脚 `config.h:7`（`#define PIN_LED_G 10`）；翻转 `output.cpp:724`（`(nowMs / 500) & 1`）。
- 不亮/极暗（绿 VF 2.5~3.6V 顶到 3.3V 上限）三级处理：① 换备件绿灯；② 飞线改灌电流（阳极接 5V、R7 120Ω→360Ω）；③ `config.h:9` 的 `LED_ACTIVE_LOW` 由 `0` 改 `1` 重烧（极性分支在 `output.cpp:709`）。
- 被问闪烁频率：答「1Hz 心跳 = 正常运行」，满足「闪烁」要求。

### 3.2 黄灯 GPIO5（v6 = 振动中常亮；v7 = 接触 2Hz 闪 + `y` 三态）

- v6 位置：`output.cpp:725`（`ledWrite(PIN_LED_Y, r.vib == 1)`，引脚定义 `config.h:8`）；三态改法（enum/`switch`/`case 'y'`/状态行/帮助行五处）已逐行写在 `v6到v7逐行讲解.md` §3.1，实测 0 warning。
- 现场演示优先用零代码方式：调试口发 `y`（仅 v7/v6+改）。

### 3.3 红灯（5V 轨常亮 = 稳压正常）

- 纯硬件：AMS1117 反馈电阻 R1=120Ω/R2=360Ω 焊反会让 Vout≈1.63V；闪烁 = 稳压跌落查 12V 输入。固件不管。

## 4. 振源驱动（设备侧，预案 #12~#14）

### 4.1 占空比与档位

- 现场：振源板 KEY4 逐次 −5%（件轻）/ KEY3 +5%（件重，起振自带 0→非0 先 100%/200ms 踢一脚）。
- 换默认：振源 `config.h` 的 `DUTY_DEFAULT_A`（新振子）/ `DUTY_DEFAULT_B`（旧振子）。
- 档位：0.5/1/2/3Hz 四档零改动（振源串口 `T0`~`T3` 或 KEY2 循环）；特定频率（如 2.5Hz）改振源 `CYCLE_TABLE` 一行。
- 被质疑精度报实测：旧振子 2Hz 段 `SS` 中位 1.99Hz、3Hz 段 2.93~2.95Hz。

### 4.2 供电（BROWNOUT 判定口诀）

- 判定：振源板串口在系统里消失几秒又回来（USB 重枚举）= 板子复位了；`q` 里 `out 90%` 是寄存器值但电机没转，检测板只读到 A≈6mg 噪声。
- 处置：直插机箱后置口（别用 hub/延长线）；检测板与振源板分开供电；有独立 12V 给振子单独供。
- 烧录时暂拔 12V（防地环路），烧完恢复。

## 5. 硬件 / 接线类（预案 #15~#17）

### 5.1 共地

- 4pin 对接天然共地（线序 ①TX=GPIO21 ②RX=GPIO20 ③GND ④VIN）。
- 外接 USB-TTL：GND 必须接，不共地一个字节都收不到（T008 踩过）；TX/RX 接反对调即可，TTL 电平无损坏风险。

### 5.2 I2C 与烧录

- 上电即 FAULT（`[MPU] 初始化失败：无应答`）→ 查 SDA/SCL 焊接与 GPIO8/9 电平；弯折后读失败 → 查跨 15.2mm 弯曲避让区的 4 根线。
- 烧录：USB 直插可烧（本机实测）；需手动进 boot → 按住 BOOT → 点 RESET → 松 RESET → 松 BOOT；CDC 口被占 → 换 `uart` 变体（非 CDC，FQBN 去掉 `:CDCOnBoot=cdc`）。

## 6. 换固件的完整流程与变体对照

流程（一步不跳）：**改 → 编译 → 宿主测试 → 烧录 → 实板验证 → 记录**。

```text
# 编译（英文临时目录，FQBN 二选一）
arduino-cli compile --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --warnings all "<英文目录>\vibmon_v6"
# 烧录（COMx 换实际口；uart 变体 FQBN 去掉 :CDCOnBoot=cdc）
arduino-cli upload -p COMx --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc" --input-dir "<变体目录>"
```
