# v5 → v6 逐行讲解（每个模块改了什么、每一处为什么改）

> 日期：2026-11-08
> 对比基准：`代码\vibmon_v5\`（T012 起草时的候选版，2026-10-30 冻结归档）→ `代码\vibmon_v6\`（T012/T013 出发版）
> 结论一句话：**v6 = v5 判据链骨架不动 + 接触逻辑推倒重写为「接触三条」（陀螺为主、加速度只管进入）
> + 启停阈值 180/150→120/80 + 分离改「净转角」+ 一行 `#V6` 调试行**。
> 实质改动四个文件：`config.h`、`state.cpp`、`state.h`、`output.cpp`（.ino 内容零改动，仅文件名）。

| 版本 | 角色 |

## 2. `config.h`（配置头）—— 接触参数大搬家 + 一组阈值下调

### 2.1 启停两门限下调：180/150 → 120/80（位置：`config.h:276-288`，v6 在原处加了 5 行依据注释）

逐行讲：

- `SS_HI_MG` `180.0f` → `120.0f`、`SS_LO_MG` `150.0f` → `80.0f`。
- 为什么改（v6 新注释，来自 `test\ss_eval.py` 回放 17 段实板数据）：
  1. 旧振子 3Hz ON 段峰值只有 150~212mg，180 起振门大半拍跨不过，启停读数 0% → 改后 59%；
  2. 弱固定振动在 150~210mg 徘徊时会在 180/150 两门之间来回跨，产生假边沿（单测\5.txt）；
  3. OFF 段最低点中位数实测 5~14mg，80 门仍有余量。
- 代价（注释里写明）：旧振子 2Hz 读数覆盖 44% → 38%，单测\4 假读数 0 → 2s，空握假读数 2 → 3s。
- 作用：这两个门只影响启停 `ssHz` 状态机，不碰接触判据本身——是给「启停节奏进接触」这条路降门槛。

### 2.2 v6 接触逻辑宏块（位置：`config.h:366-412`，全新增，10 只宏）

逐行讲（全部 `#ifndef` 包住，可 `-D` 覆盖；块首注释就是人类原话的三条规则）：

| 宏（行号） | 默认 | 作用 |
|---|---|---|
| `CT_V6_ENABLE`（376-378） | 1 | 总开关。0 = 整套 v6 接触逻辑不编译，行为回到 v5 + T011 |
| `GYRO_LP_HZ`（379-381） | 4.0f | 陀螺两级一阶低通截止。手指动作 <2Hz、振动 ≥80Hz，4Hz 滤掉振动、留下手指转动 |
| `CT_SETTLE_ENABLE`（382-384） | 1 | 0 = 不要求「手指已停下」（实板若发现振动时滤波后仍过门限，现场可关） |
| `CT_SETTLE_DPS`（385-387） | 10.0f | 低通后合成角速度低于此值 = 手指不动 |
| `CT_SETTLE_MS`（388-390） | 150 | 连续不动这么久 = 已停下 |
| `CT_RELEASE_DEG`（391-393） | 10.0f | 接触后累计转过此角度 = 分离（含继续收拢 = 物体滑脱） |
| `SS_CLEAR_ON_SETTLE`（394-396） | 1 | 每次收拢后第一次停下时清启停历史，丢掉收拢/撞击瞬态留下的边沿 |
| `SS_TRAIL_IN_CONTACT`（400-402） | 跟随 CT_V6_ENABLE | 已接触时启停读数改取「最新连续一致段」，不再被离群周期拖住 |
| `CT_RELEASE_NET`（407-409） | 1 | 分离用「净转角」：来回摆互相抵消，单向转动才累积 |
| `CT_RELEASE_TAU_MS`（410-412） | 500 | 净转角泄漏时间常数（残余偏置最多积到 0.5dps×0.5s = 0.25°） |

为什么必须有「停下」这一条（块内注释）：原始陀螺不能直接判静止——实测闭合振动时 `gyroW` 中位数 22~93dps（55 个 CSV），必须先低通再判。陀螺削顶（强振动）时滤波暂停，按「已停下」处理：强振动下手指转动量测不了，不让它拦接触，分离仍由角度门兜底。

### 2.3 配套编译期检查（位置：`config.h:700-707`）

逐行讲：`CT_V6_ENABLE=1` 时必须 `CT_MODE=4`（依赖陀螺闭合角）、必须 `CT_HOLD_ENABLE=1`（启停进入路径依赖它）、`CT_SETTLE_MS` 不能为负。

作用：v6 接触逻辑与模式 4 / hold 强绑定，配错组合编译期直接报错，不带病上板。

## 3. `state.h`（结果结构）—— Result 多 3 个 v6 字段 + 1 个测试钩子

位置：`state.h:77-80`（结构体 `Result` 内，`gyroW` 之后；77 为 v6 注释行）与 `state.h:148`（测试钩子声明）。

逐行讲：

1. `float gyroLpW;` —— 低通后合成角速度：去掉振动后的「手指转动速度」，是「已停下」判据的输入。
2. `bool settled;` —— 手指已停下标志（`gyroLpW < CT_SETTLE_DPS` 持续 `CT_SETTLE_MS`，或陀螺削顶）。
3. `float ctMovedDeg;` —— 接触后累计（净）转角；`> CT_RELEASE_DEG` 判分离。
4. `void stateTestSetContact(uint8_t c);`（`state.h:148`）—— 回放用：按日志 CT 列直接设置接触态。

作用：把 v6 的三个新观测量放进 `Result`，调试行、宿主测试、回放脚本都能直接读。

## 4. `state.cpp`（判据链）—— v6 的全部新逻辑（+138 行，零删除）

### 4.1 核心块：滤波、停下判据、净转角（位置：`state.cpp:80-157`，紧跟 `ctHoldClear()` 之后，全新增 78 行）

逐段讲：

1. 状态变量（`state.cpp:80-88`）：`s_gyroLp1[3]` / `s_gyroLp2[3]` 两级一阶低通、`s_settleUs` 连续不动计时、`s_settleReal` 真停下标志、`s_ssClearedThisClose` 本轮收拢是否已清过启停、`kGyroLpA` 低通系数、`s_moveVec[3]` 净转角向量与泄漏系数 `kMoveLeak`。
2. `moveClear()` / `v6Clear()`（`state.cpp:90-101`）：清接触相关量与滤波状态。
3. `gyroLpStep(f)`（`state.cpp:103-156`）—— **每个陀螺样本（250Hz）调一次**，v6 的心脏：
   - `!f.gyroValid` 直接返回；
   - `f.gyroClipped`（削顶）：滤波不吃削顶样本（会带进直流偏差），置 `settled=true` 直接返回——强振动按「已停下」处理；
   - 两级一阶低通逐轴推进，合成 `s_r.gyroLpW`；
   - `w < CT_SETTLE_DPS` 累加 `s_settleUs`，否则清零；持续 ≥ `CT_SETTLE_MS` → `s_settleReal=true`；
   - `CT_SETTLE_ENABLE` 开时 `s_r.settled = s_settleReal`（否则恒 true）；
   - `CT_RELEASE_NET` 分支：接触时每轴 `s_moveVec[a] = s_moveVec[a]*kMoveLeak + 低通角速度*dt`，合成后**取本次接触最大值**写 `ctMovedDeg`——泄漏只用来抵消来回摆，过门之后不因衰减「撤销」分离；未接触时清零。`#else` 分支是备选的「只积分超门限部分」。

作用：把「手指动没动」「转了多少」从被振动淹没的原始陀螺里解出来——这是接触三条能成立的前提。

### 4.2 `ssEvaluate()` 尾部：接触中取最新一致段（位置：`state.cpp:224-239`，全新增 16 行）

逐行讲：`SS_TRAIL_IN_CONTACT` 开且 `s_r.contact==1` 时，从最新周期往回收连续一致（`SS_CONSIST_RATIO` 内）的一段作为启停周期集合；接触为 0 时规则不变。

作用（实板依据 `V6\4.txt/5.txt`）：0.5Hz 首读数晚 8.0/15.9s，原因是起振前离群周期（如 7.94s）占住 4 周期窗口；改后接触中 2 个周期即出读数。只接触中放宽，不无条件放宽（否则空握假读数 11 → 27 秒）。

### 4.3 `combineContact()`：三条规则的落点（位置：`state.cpp:403-409`，`403` 为 `#if CT_V6_ENABLE`，全新增 7 行）

逐行讲：

```cpp
if (!postureOk) return 0u;                                        // 姿态门退出 = 张开 → 分离
if (prev) return (s_r.ctMovedDeg > CT_RELEASE_DEG) ? 0u : 1u;     // 保持：不看加速度，只看净转角
return (s_r.settled && ((ampEff && freqEff) || ssEff)) ? 1u : 0u; // 进入：已停下 + 振动证据
```

- 进入 = 收拢（角度门）+ **已停下** + 振动证据（幅值且频率，或启停 ≥1.5Hz——继承 T011）；
- 保持 = 不再看加速度、不再有 `CT_HOLD_MS` 超时，只有陀螺能退出；
- 分离 = 角度门张开（第一行）**或**净转角过 10°（第二行）。

作用：人类授权原话三条规则的一对一翻译。注意证据顺序与 v5 反转——v5 是「加速度为主、陀螺辅助」，v6 是「陀螺先、加速度只管进入」。

### 4.4 `ctStep()` 里两处小改动（位置：`state.cpp:538-541` 与 `state.cpp:561-577`）

逐行讲：

1. 姿态门退出分支开头加 `moveClear();`（538-541）——分离时清转角，下次接触从 0 重新累计。
2. 姿态门处理里加两段（561-577）：
   - 陀螺没上线或停更（`GYRO_STALE_MS` 超时）时置 `settled=true`——没有陀螺时不拦接触，退回 v5 行为；
   - `SS_CLEAR_ON_SETTLE`：收拢后**第一次真停下**（`s_settleReal`）时 `ssClearPeriods()` + `s_haveEdge=false`——收拢/撞击瞬态留下的边沿全部丢掉；张开时复位 `s_ssClearedThisClose`，下次收拢重新允许清一次。

作用：进入瞬间的历史脏数据（撞击边沿、旧周期）不再污染新一次接触。

### 4.5 四处复位点补 `v6Clear()`（位置：`state.cpp:826-828`、`913-915`、`954-956`、`1055-1057`，各处 826/913/954/1055 为 `#if CT_V6_ENABLE`）

逐行讲：四个「清接触状态」的出口（平放基准提交、清平放基准、标定应用、`stateReset()`）各加 `#if CT_V6_ENABLE` + `v6Clear();` + `#endif`。

作用：任何重置路径都把低通状态、停下计时、净转角、清启停标志一并归零，防上一轮残留。

### 4.6 `stateOnFrame()` 接入每样本滤波（位置：`state.cpp:1197-1199`）

逐行讲：`angleStep(f, tUs);` 之后加 `#if CT_V6_ENABLE` + `gyroLpStep(f);` + `#endif`。

作用：滤波跟随陀螺原始节奏（250Hz）推进，与 100Hz 包络节奏无关——这是它和 v8 `layerPush`（每包络点一次）的关键节奏区别。

### 4.7 测试钩子（位置：`state.cpp:1269`，1 行）

逐行讲：`void stateTestSetContact(uint8_t c) { s_r.contact = c; }`——供回放脚本按日志 CT 列复现接触态。

## 5. `output.cpp`（输出）—— 一行 `#V6` 调试行（+5 行）

位置：`output.cpp:692-697`（`debugLine()` 内、既有调试行之后）。

逐行讲：

```cpp
#if CT_V6_ENABLE
  outPrintf("#V6 closed=%u ang=%.1f lpW=%.1f settled=%u moved=%.1f\n", ...);
#endif
```

作用：按 `d` 打开调试后，v5 的调试行旁边多一行 v6 观测量——闭合角、低通角速度、是否已停、接触后净转角。实板调 `CT_SETTLE_DPS` / `CT_RELEASE_DEG` 就看这行。

## 6. 为什么这么改：v5 的三个实测堵点（T012 数据依据）

| v5 堵点 | 数据 | v6 对策 |
|---|---|---|
| 无振动接触判不了 | 纯加速度占比：负样本滑窗 17~33%，3Hz 正样本 12~49%，分不开 | 接触改三条，加速度只参与「进入证据」 |
| 原始陀螺判不了静止 | 闭合振动时 gyroW 中位数 22~93dps | 两级 4Hz 低通后再判停下（§4.1） |
| 旧振子 2Hz 接触掉 4 次 | 累计绝对角速度把启停反扭矩的来回摆也算成转动 | 净转角（带泄漏积分）来回摆抵消（§4.1） |

宿主测试链（口径演变，背这条链）：v5 宏全关 46/46 → v5+T011 宏开 65/65 → T011-2 后 67/67 → **v6 初版 85/85**（关 v6 回 67/67）→ RT012b 修正补 V6/V7 用例 → **v6 最终 89/89**（与 v7/v8 同口径）。
固件：v6 `build_uart\` SHA `0bf3c2fd…`，0 warning；v5 冻结基线 CDC 368804B Flash / 30260B RAM。

实板验收（RT012-20261106b 两轮）：松手掉 0、振停 8s 手不动保持 1、无振动夹物 0、0.5/1/3Hz 启停进接触、空握第二轮 0 误报。撞击抖动判接触被数据否决（空握撞击 172~1167mg 与夹 4cm 152~887mg 完全重叠）。

## 7. 一页速记（现场问「v5 怎么到 v6」就答这段）

- 只动四个文件：`config.h`（宏与阈值）、`state.cpp`（+138 行新逻辑）、`state.h`（+3 字段+钩子）、`output.cpp`（+5 行调试）；dsp/posture/sampler/mpu 与 .ino 逐字节不变。
- 判据反转：v5「加速度为主、陀螺辅助」→ v6「陀螺先：进入=收拢+已停下+振动证据；保持=不看加速度；分离=只看陀螺（张开或净转角 >10°）」。
- 关键新增：两级 4Hz 陀螺低通 + 停下判据（10dps×150ms）+ 净转角（500ms 泄漏）+ 接触中启停取最新一致段 + 收拢首停清启停历史。
- 阈值：`SS_HI/LO` 180/150 → 120/80（旧振子 3Hz 读数 0% → 59% 的代价是 2Hz 覆盖 -6%）。
- 现场开关：`CT_V6_ENABLE=0` 一键回 v5+T011 行为；实板调参必开 `d` 看 `#V6` 行。
