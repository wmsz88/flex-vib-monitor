- **vibmon_v6**：最终版/出发版，上板验收过，归档不动。
- **vibmon_v7**：现场适配参考版 = v6 判据链（逐字节相同）+ 黄灯/`y` + 三预案宏。
- **vibmon_v8**：分层检测实验版 = v6 判据链（逐字节相同）+ 旁挂分层观察层；不继承 v7 的现场件。
- **vibmon_v9**：平放基准时机实验版 = v6 判据链（判据不动）+ `CT_REF_REOPEN_ONLY=1`（张开才重采平放基准，防握物姿态被当零点）；删了 v8 分层件；`contact_test` 93/93（新增 R1/R2）。
- **vibmon_v5**：v6 的前身（加速度为主的接触判据），2026-10-30 冻结归档，只做历史追溯与回退。
