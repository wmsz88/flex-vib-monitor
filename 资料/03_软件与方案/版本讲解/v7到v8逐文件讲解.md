# v7 → v8 逐文件讲解（新模块：模块 + 位置 + 作用）

> 日期：2026-11-08
> 对比基准：`代码\vibmon_v7\`（现场适配参考版）→ `代码\vibmon_v8\`（T014 分层检测实验版）
> 结论一句话：**v8 = 在 v7 之外另开的实验线，基线由 v6 复制，核心是新增「分层检测」模块
>（`layered_detection.h/.cpp`），并接到 state（喂数据）和 output（打调试行）**。
> v8 **不是** v7 加分层，也不继承 v7 的黄灯三态/三预案宏——v7 的角色是现场适配参考版，v8 是算法实验版。

## 1. 版本关系（先背这段）

| 版本 | 基线 | 角色 |
|---|---|---|
| vibmon_v6 | — | 最终版 / 出发版（上板验收过） |
| vibmon_v7 | 由 v6 拷贝 | 现场适配参考版（黄灯 + 三预案宏，判据链与 v6 逐字节相同） |
| vibmon_v8 | 由 v6 拷贝 | 分层检测实验版（判据链与 v6 逐字节相同，只旁挂观察层） |

v8 的纪律（`README.md`）：不改 `$VD` 帧格式、不改 V6 接触判据、分层输出不反向影响 `Result`、
`LAYERED_DETECT_ENABLE=0` 时完整回到 V6 行为。

## 2. 新增模块：`layered_detection`（分层检测，v8 的全部新增逻辑都在这里）

### 2.1 `layered_detection.h`（接口，全文件 34 行）

位置：`layered_detection.h:1-34`（新增文件，v7 没有）。

逐段讲：

1. `struct LayerInput`（`layered_detection.h:6-15`）——每 10ms 推一次的输入快照：
   - `tUs` 时间戳、`envMg` 包络值、`freqHz` 频率、`ssHz` 步进频率；
   - `closed` 手指是否收拢（角度过线）、`settled` 手指是否已停下、`freqValid` / `ssValid` 该值是否有效。
   - 作用：分层模块不进采样/滤波内部，只拿 state 已经算好的结果，保证与 V6 判据同源。
2. `struct RealtimeLayerResult`（`layered_detection.h:17-20`）——实时层输出：`vib`（分层振动标志）、`contact`（分层接触标志）。
3. `struct UniformLayerResult`（`layered_detection.h:22-30`）——均匀层输出：频率中位数 `freqMedian`、频率离散度 `freqSpread`、包络中位数/离散度、`ssMedian`、有效率 `validRatio`、`stable`（稳态标志）。
4. 四个接口（`layered_detection.h:32-34`）：`layerInit()` 初始化、`layerPush()` 推一帧、`layerRealtime()` / `layerUniform()` 取结果。
   - 作用：state 只调 `layerPush`，output 只调两个取数函数，模块边界干净。

### 2.2 `layered_detection.cpp`（实现，160 行）

位置：`layered_detection.cpp:1-160`（新增文件）。

逐段讲：

1. 模块内部状态（`layered_detection.cpp:8-20`）：
   - `s_realtime` / `s_uniform` 两个输出结构；
   - `s_freq[LAYER_WINDOW_N]` / `s_env` / `s_ss` / `s_freqValid` / `s_ssValid`：滑动窗口（默认 50 点 = 0.5 s）；
   - `s_head` / `s_count`：环形缓冲头与已存数量；
   - `s_hiCnt` / `s_loCnt`：实时层振动确认计数（滞回用）。
   - 作用：全部静态分配、无堆，RAM 用量编译期由 `LAYER_WINDOW_N` 定死。
2. `medianOf()`（`layered_detection.cpp:23-36`）与 `percentileOf()`（`layered_detection.cpp:38-53`）：
   - 拷贝到临时数组 → 插入排序 → 取中位数 / P10 / P90。
   - 作用：抗野值。单帧频率可能跳，中位数和离散度比瞬时值可信。
3. `layerInit()`（`layered_detection.cpp:55-68`）：清两个输出结构、memset 五个窗口、`s_head/s_count/s_hiCnt/s_loCnt` 归零。
   - 调用点：`state.cpp:1036` 的 `stateReset()` 里（见 §3.2）。作用：复位/重开跑时分层层一起清干净。
4. `layerPush()`（`layered_detection.cpp:70-157`）——模块主逻辑，每包络点一次：
   - **实时层振动**（`layered_detection.cpp:73-95`）：和 V6 的 SS 状态机同思路——上行滞回 `envMg > LAYER_VIB_HI_MG` 连续 `LAYER_VIB_CONFIRM` 次才置 1；下行 `< LAYER_VIB_LO_MG` 连续 N 次才清 0；否则计数清零。
     作用：给出一个「更钝但更稳」的振动标志，供和实时 `r.vib` 互相印证。
   - **实时层接触**（`layered_detection.cpp:96-104`）：`closed=0` 直接清 0；收拢后要 `settled` 且有证据（`vib || ssValid || freqValid`）才置 1——与 V6 接触三条件语义一致，但用分层自己的数据。
   - **滑动窗口入队**（`layered_detection.cpp:106-113`）：按 `s_head` 环形写入，`s_count` 封顶 `LAYER_WINDOW_N`。
   - **均匀层统计**（`layered_detection.cpp:115-150`）：把窗口内有效值捞出来（频率要 `freqValid && >0`，包络要 `>=0`，SS 要 `ssValid && >0`），分别算中位数与 `(P90-P10)/中位数` 离散度。
     作用：一层「稳不稳、匀不匀」的画像，适合判断「持续稳态振动」这类场景。
   - **stable 判据**（`layered_detection.cpp:152-156`）：`nFreq>0` 且 `freqSpread <= LAYER_FREQ_SPREAD_MAX` 且 `envSpread <= LAYER_ENV_SPREAD_MAX` 且 `validRatio >= LAYER_VALID_RATIO_MIN` 才置 1。
   - `layerRealtime()` / `layerUniform()`（`layered_detection.cpp:159-160`）：返回结构体副本，无副作用。

## 3. `config.h`（v8 的改动：删 v7 的预案宏 + 加分层参数）

### 3.1 删掉的（v7 有、v8 没有）

位置：对照 `config.h:56-70`（v7 的三预案宏）与 `config.h:738-749`（v7 的参数检查）。

v8 把 `COMP_FRAME_CSV / COMP_FRAME_DIV / COMP_FRAME_GATED` 三组宏、它们的 `#error` 检查、以及 `output.cpp` 里对应实现全部移除，`COMP_FRAME_ENABLED` 回到 `0`。

作用：预案宏是 v7 的现场适配件，不属于算法实验线；留在 v8 只会干扰「这一版改了什么」的判断。

### 3.2 新增的（T014 分层检测参数）

位置：`config.h:253-288`（插在 `TH_LO_MIN_MG` 与 `SS_CONFIRM` 之间）。

逐行讲（全部 `#ifndef` 包住，可用 `-D` 覆盖）：

| 宏（行号） | 默认 | 作用 |
|---|---|---|
| `LAYERED_DETECT_ENABLE`（255-257） | 1 | 总开关。0 = 分层代码整段不编译，行为与 V6 完全一致（这是「实验版不污染出发版」的保险丝） |
| `LAYER_WINDOW_N`（258-260） | 50 | 滑动窗口点数（50 点 = 0.5 s @100Hz 包络）。窗口越大越平滑、越迟钝 |
| `LAYER_VIB_HI_MG`（261-263） | 120.0f | 实时层振动置 1 的上行门限（包络 mg） |
| `LAYER_VIB_LO_MG`（264-266） | 80.0f | 实时层振动清 0 的下行门限（滞回带 80~120 mg，防抖） |
| `LAYER_VIB_CONFIRM`（267-269） | 3 | 连续 3 个包络点过线才翻转（30 ms 确认） |
| `LAYER_FREQ_SPREAD_MAX`（270-272） | 0.08f | 均匀层 `stable` 判据：频率 (P90-P10)/中位数 ≤ 8% |
| `LAYER_ENV_SPREAD_MAX`（273-275） | 0.25f | 均匀层 `stable` 判据：包络离散度 ≤ 25% |
| `LAYER_VALID_RATIO_MIN`（276-278） | 0.70f | 窗口内有效点占比 ≥ 70% 才允许判稳 |
| `LAYER_VIB_HI_MG_INT` / `LAYER_VIB_LO_MG_INT` / `LAYER_VALID_RATIO_MIN_INT`（280-288） | 120/80/70 | 整数镜像：`#if` 不能比较浮点字面量，给编译期断言用 |

### 3.3 配套参数检查

位置：`config.h:786-798`（在模式 3/4 检查之后）。

逐行讲：

- `LAYER_WINDOW_N` 必须在 2~512（窗口按此静态分配，过大会吃 RAM）；
- `LAYER_VIB_CONFIRM` 必须 >= 1（否则单帧即翻转，失去确认意义）；
- `LAYER_VIB_HI_MG_INT` 必须大于 `LAYER_VIB_LO_MG_INT`（否则滞回带反了，振动标志会在阈值处抖动）；
- `LAYER_VALID_RATIO_MIN_INT` 必须在 0~100。

作用：参数配错在编译期报错，不带上板。

## 4. `state.cpp`（判据链文件，但 v8 只做「旁挂喂数」，不动任何判定）

### 4.1 头部接入

位置：`state.cpp:3`（`#include "layered_detection.h"`）与 `state.cpp:10-12`（`#if LAYERED_DETECT_ENABLE` + `static LayerInput s_layerInput = {};` + `#endif`）。

作用：拿到分层模块的接口和一个输入快照变量；开关关掉时这行编译成空。

### 4.2 `stateReset()` 清分层

位置：`state.cpp:1035-1038`（`#if LAYERED_DETECT_ENABLE` 里的 `layerInit();` 与 `s_layerInput = LayerInput{};`，在 `clearEdgeInterp();` 之后、角度重起算注释之前）。

逐行讲：`#if LAYERED_DETECT_ENABLE` 里两句——`layerInit();` 和 `s_layerInput = LayerInput{};`。

作用：复位时把滑动窗口、滞回计数、两个输出结构清空，避免上一轮残留数据污染新一轮统计。

### 4.3 `stateOnFrame()` 里按包络节奏喂数（v8 最重要的接线）

位置：`state.cpp:1220-1234`（在 `ssStep(f.env, tUs); ctStep(f.ctDev, tUs);` 之后；1220 为 `#if LAYERED_DETECT_ENABLE`，1221-1223 为节奏约束注释，1224-1232 为 8 个字段赋值，1233 为 `layerPush`，1234 为 `#endif`）。

逐行讲：

1. 位置为什么在这里：`f.env` 只在 `envReady`（每 `ENV_HOP` 个样本一次，100Hz）时才有效。
   若放在每样本路径上，其余样本会填 0，实时层的确认计数永远凑不满、均匀层的中位数也被 0 拉平——这是分层层的节奏约束（v8 代码注释原话）。
2. 8 个字段逐个填：`tUs`、`envMg=f.env`、`freqHz=s_r.freqHz`、`ssHz=s_r.ssHz`、
   `closed=(s_r.closeAngleDeg >= ANGLE_CLOSED_DEG)`、`settled=s_r.settled`、`freqValid=s_r.freqValid`、`ssValid=s_r.ssValid`。
3. `layerPush(&s_layerInput);` 推给分层模块。

作用：分层模块只在「V6 判据链看完一帧」之后旁挂收数据，输出什么完全不影响 `s_r`（接触三条、启停、SS 全部照旧）。

### 5.2 新增的：`#LAYER` 调试行

位置：`output.cpp:2`（`#include "layered_detection.h"`）与 `output.cpp:700-708`（`debugLine()` 内、`#V6` 行之后）。

逐行讲：

```cpp
#if LAYERED_DETECT_ENABLE
  const RealtimeLayerResult lr = layerRealtime();
  const UniformLayerResult lu = layerUniform();
  outPrintf("#LAYER vib=%u ct=%u stable=%u fmed=%.1f fspread=%.3f amed=%.1f aspread=%.3f ssmed=%.2f valid=%u\n", ...);
#endif
```

- `lr.vib` / `lr.contact`：分层实时层的振动与接触标志；
- `lu.stable`：均匀层稳态标志；
- `fmed` / `fspread`：频率中位数与离散度；`amed` / `aspread`：包络中位数与离散度；
- `ssmed`：SS 中位数；`valid`：窗口有效点占比（%）。

作用：按 `d` 打开调试后，`#V6` 行旁边多一行 `#LAYER`，两套判据同屏对照，实板调参（改 `LAYER_*` 宏）时直接看数字。
调用链：`vibmon_v8.ino:174` 的 `stateOnFrame(f, s.tUs)` 喂数 → `vibmon_v8.ino:715` 定时调 `debugLine()` 打印。

## 8. 一页速记（现场问「v7 到 v8 变了什么」就答这段）

- v8 和 v7 是**两条线**：都以 v6 为基线；v7 = 现场适配件，v8 = 分层检测实验。
- 新增模块 `layered_detection`：
  - `layered_detection.h`：`LayerInput` 输入快照 + 两层输出结构 + 4 个接口；
  - `layered_detection.cpp`：实时层（滞回 + 3 点确认的振动/接触）+ 均匀层（50 点滑窗中位数/P90-P10 离散度/有效率/stable）。
- 接线只有两处：
  - `state.cpp:1220-1234` 每包络点调 `layerPush()`（旁挂喂数，不动判据）；
  - `output.cpp:700-708` `debugLine()` 加 `#LAYER` 行（只打印）。
- `config.h`：删 v7 三预案宏，加 9 个 `LAYER_*` 宏 + 4 条编译期检查；`LAYERED_DETECT_ENABLE=0` 一键回 V6 行为（`v6_fallback` 89/89 证明）。
- 删 v7 的黄灯三态/CSV/分频/门控及其测试 `led_test`；`_variants\` 清空。
