# 指示灯闪烁 / 常亮改法（绿 · 黄）

> 日期：2026-11-08
> 覆盖需求：**绿灯**的闪烁与常亮、**黄灯**的「接触常亮/闪烁」与「振动常亮/闪烁」。
> 行号均已对 v6/v7 源码核对。红灯是 5V 轨硬件直连（固件不可控），不在本文范围。

## 0. 灯的硬件与现有行为（先认清有什么）

| 灯 | 引脚 | 极性宏 | 现有行为（v6 = v7 判据链） | 驱动代码 |
|---|---|---|---|---|
| 绿 | `PIN_LED_G` = GPIO10（`config.h:7`） | `LED_ACTIVE_LOW`（`config.h:9`） | RUN 态 1Hz 心跳闪（500ms 翻转）；CAL 态常亮；FAULT 态常灭 | `output.cpp:708-714` `ledWrite()`、`721-734` `ledUpdate()` |
| 黄 | `PIN_LED_Y` = GPIO5（`config.h:8`） | 同上 | **v6**：RUN 态振动中常亮（`r.vib==1`）、故障 4Hz 快闪；**v7**：RUN 态接触 2Hz 闪 + `y` 三态 AUTO/ON/OFF | 同上；v7 三态在 `output.cpp:32-34`（状态）、`777-781`（分支）、`908-911`（`y` 命令） |

底层的两个事实（所有改法都建立在这上面）：

1. **每 500ms 一次 `ledUpdate()` 翻转 = 1Hz 闪烁**；`(nowMs / N) & 1` 是闪烁的通用写法：N=500 → 1Hz、N=250 → 2Hz、N=125 → 4Hz。
2. `ledWrite(pin, true)` 即常亮、`ledWrite(pin, false)` 即常灭（极性由 `LED_ACTIVE_LOW` 统一处理，`output.cpp:709-713`）。

模式来源：`enum LedMode { LED_RUN, LED_CAL, LED_FAULT }`（`output.h:17`），由 `ledSet()` 切换（`output.cpp:716-719`）；主程序在故障时 `ledSet(LED_FAULT)`（`vibmon_v6.ino:28`）、恢复运行 `ledSet(LED_RUN)`（`:70`）、标定期间 `ledSet(LED_CAL)`（`:80`）。**现场演示要改的是 `LED_RUN` 分支，别动 FAULT/CAL 的灯语义。**

## 1. 黄灯：接触 常亮 / 闪烁 + 振动 常亮 / 闪烁（一条命令全切换）

现有能力盘点：

- **接触 2Hz 闪烁**：v7 已内置（AUTO 态，`output.cpp:780`）。
- **接触常亮**：v7 `y` 命令 ON 态（`:778`）已内置。
- **振动常亮**：v6 已内置（`r.vib==1` 常亮，`:725`）。
- **振动闪烁 / 一个口切换五种模式**：要小改。下面给出把 v7 的黄灯三态扩成五态的完整改法（v7 改最顺，因为它已有 `y` 命令与 `s_ledY` 状态机）。

### 1.1 五态黄灯（v7 上改，含振动闪烁）

改 3 处，全部在 `代码\vibmon_v7\output.cpp`：

**① 状态定义（`output.cpp:32-34`，把三态扩成五态）：**

```cpp
enum LedYMode : uint8_t { LEDY_AUTO = 0, LEDY_ON, LEDY_OFF, LEDY_VIB_ON, LEDY_VIB_BLINK, LEDY_COUNT };
static uint8_t s_ledY = LEDY_AUTO;
static const char* const kLedYName[LEDY_COUNT] = { "AUTO", "ON", "OFF", "VIB_ON", "VIB_BLINK" };
```

**② `LED_RUN` 分支（`output.cpp:777-781`，`switch` 里加两个 case）：**

```cpp
        case LEDY_VIB_ON:    ledWrite(PIN_LED_Y, r.vib == 1); break;   // 振动常亮（= v6 行为）
        case LEDY_VIB_BLINK: ledWrite(PIN_LED_Y, (r.vib == 1) && (((nowMs / 250) & 1) != 0)); break; // 振动 2Hz 闪
```

（接触 2Hz 闪 = AUTO、接触常亮 = ON、常灭 = OFF，原样保留。）

**③ `y` 命令不用改**：`s_ledY + 1 % LEDY_COUNT` 自动循环到五态，回显名字也自动带上——这就是当初把它写成枚举表的好处。

改完按 `y` 的循环：`AUTO（接触2Hz闪）→ ON（接触常亮）→ OFF（常灭）→ VIB_ON（振动常亮）→ VIB_BLINK（振动2Hz闪）→ AUTO`。现场想直接跳到某一态，把 `% LEDY_COUNT` 循环改成「按 `1`~`5` 数字选态」也行，但循环最省事、命令表不用加行。

宿主测试注意：`test\led_test.cpp` 的 64 项断言写死三态计数与名字，扩五态后该项会挂——照 CSV 同理属"断言口径过时"，改断言或临时跳过该项，其余测试必须与基线一致。

### 1.2 只要某一固定行为的极简改法（v6/v7 通用）

不想加状态机、现场就演示一种，直接改 `LED_RUN` 分支一行（v6 在 `output.cpp:723-726`，v7 在 `777-781`）：

| 要的行为 | 那一行写 |
|---|---|
| 接触常亮 | `ledWrite(PIN_LED_Y, r.contact == 1);` |
| 接触 2Hz 闪 | `ledWrite(PIN_LED_Y, (r.contact == 1) && (((nowMs / 250) & 1) != 0));` |
| 接触 1Hz 闪 | 同上把 `250` 换 `500` |
| 振动常亮（v6 默认） | `ledWrite(PIN_LED_Y, r.vib == 1);` |
| 振动 2Hz 闪 | `ledWrite(PIN_LED_Y, (r.vib == 1) && (((nowMs / 250) & 1) != 0));` |
| 振动 4Hz 快闪 | 同上把 `250` 换 `125` |

每次只改一行 → 编译 → 烧录；比五态机更笨但更稳，适合「评委只看一种」的情况。

## 2. 绿灯：闪烁与常亮

赛题要求绿灯「闪烁 = 正常运行」，默认 1Hz 心跳已达标；要演示"可控常亮"才需要改。

### 2.1 加 `g` 命令：绿心跳 / 常亮切换（v7 改法，与 `y` 对称）

改 3 处，全部在 `代码\vibmon_v7\output.cpp`：

**① 状态（仿照 `s_ledY` 三兄弟，加在 `output.cpp:32-34` 之后）：**

```cpp
enum LedGMode : uint8_t { LEDG_HEARTBEAT = 0, LEDG_ON, LEDG_COUNT };
static uint8_t s_ledG = LEDG_HEARTBEAT;
static const char* const kLedGName[LEDG_COUNT] = { "HEARTBEAT", "ON" };
```

**② `LED_RUN` 分支（`output.cpp:776` 一行换成 switch）：**

```cpp
      switch (s_ledG) {
        case LEDG_ON: ledWrite(PIN_LED_G, true); break;
        default:      ledWrite(PIN_LED_G, (nowMs / 500) & 1); break;   // 1Hz 心跳
      }
```

**③ 命令（`output.cpp:908-911` 的 `case 'y'` 之后加）：**

```cpp
      case 'g':
        s_ledG = (uint8_t)((s_ledG + 1u) % (uint8_t)LEDG_COUNT);
        outPrintf("[LEDG] %s\n", kLedGName[s_ledG]);
        break;
```

再顺手把帮助行（`output.cpp:874`）的 `y 黄灯` 改成 `y 黄灯 | g 绿灯`、`S` 状态行（v7 `:412-413` 黄灯行旁边）加一行绿灯状态打印——不改也能用，只是 `?` 和 `S` 里看不见。

注意：**FAULT 态绿灯常灭、CAL 态常亮是刻意的故障/标定语义，`g` 只管 RUN 态**——切到常亮后如果板子进了故障态，绿灯照样灭，这是对的，不要"修"它。

### 2.2 只要常亮的极简改法

直接把 `LED_RUN` 分支的 `output.cpp:776`（v6 `:724`）改成 `ledWrite(PIN_LED_G, true);`——常亮；改回 `(nowMs / 500) & 1` 即恢复 1Hz 心跳。要慢闪演示就 `1000`（0.5Hz）、快闪 `250`（2Hz）。

## 3. 改哪里 & 怎么验收（两灯通用）

| 步骤 | 内容 |
|---|---|
| 选目录 | 演示黄灯五态/绿灯 `g` → 改 v7（`y`/`g` 命令已就位）；单行为 → v6/v7 都行，改一行 |
| 编译 | 英文临时目录，`esp32:esp32:esp32c3:CDCOnBoot=cdc --warnings all`，0 warning |

| 实板 | RUN 态逐态演示并记录；确认 FAULT/CAL 语义未被误改（拔 SDA 模拟故障：绿灭黄 4Hz） |
| 回退 | 恢复 `output.cpp` 对应行 / 重烧 `def` 变体 |

## 4. 一页速记

- `(nowMs / N) & 1`：N=500 → 1Hz、250 → 2Hz、125 → 4Hz；`ledWrite(pin, true/false)` = 常亮/常灭。
- 黄灯：接触常亮/闪 v7 已内置（`y` 的 ON/AUTO）；振动常亮 v6 内置；振动闪烁用五态扩法（§1.1 三处改动）或一行极简改法（§1.2 表）。
- 绿灯：1Hz 心跳默认达标；要常亮加 `g` 命令（§2.1 三处）或一行改法（§2.2）；FAULT/CAL 灯语义不许动。
- 一切改动只碰 `LED_RUN` 分支；`LED_FAULT`（绿灭黄 4Hz）与 `LED_CAL`（双常亮）是故障与标定的语义信号，改了会掩盖故障。
