# 实板测试模式（助手 × 人 协作）

> 建立日期：2026-11-02 ｜ 适用：工科赛 vibmon 实板/外部测试

## 一句话

助手在**一轮回复里**跑完整个外部测试：**后台连续采集 → 语音播报逐步给指令 → 人按提示做动作 → 一轮结束出结果**。
不用掐秒表、不用按回车、不用预先排固定时间表。

## 三个组件

| 组件 | 做法 |
|---|---|
| 后台采集 | `python -X utf8 -u logger.py --sensor COM9 --out live.csv --secs 1800`（1Hz 采 `#SWEEP`，带墙钟时间戳；**开串口会复位模块**） |
| 语音播报 | PowerShell `Add-Type -AssemblyName System.Speech`，中文音色 `Microsoft Huihui`，`$s.Speak("...")` 直接出声 |
| 控振源 | 打开 COM7 写单字符：`h`=100%、`9`=90%、`8`=80%、`p`=55%(带起步踢一脚)、`+/-`=步进5%、`z`=停；每次 `Open→Write→Close` |

## 每步的固定形状（助手侧）

```
语音播报「这一步要做什么、保持多久」  →  执行一条命令（发串口 / Start-Sleep N）  →  读一眼 live.csv 报当前值
```

这些**全部串在同一条回复内**；人只负责照着动，手不用离开夹具。

## 完整例子：接触判据 × 振源下扫（2026-11-02 实跑）

| 步 | 助手语音播报 | 助手命令 | 人的动作 |
|---|---|---|---|
| 0 | "请张开保持，12 秒后我复位模块" | `Start-Sleep 15` → 起 logger | 张开不动 |
| 1 | "基线就绪，请闭合夹住 4cm 方块，25 秒" | `Start-Sleep 25` | 闭合夹住 |
| 2 | "把振源开到 100%，保持 20 秒" | COM7 `h` → `Start-Sleep 20` | 继续夹住 |
| 3 | "降到 80%，保持 18 秒" | COM7 `8` → `Start-Sleep 18` | 继续夹住 |
| 4 | "降到 65%，保持 18 秒" | COM7 `p`,`+`,`+` → `Start-Sleep 18` | 继续夹住 |
| 5 | "降到 55%（约 80Hz），保持 18 秒" | COM7 `p` → `Start-Sleep 18` | 继续夹住 |
| 6 | "我关振源，看 ct 回落，12 秒" | COM7 `z` → `Start-Sleep 12` | 继续夹住 |
| 7 | "可以松手了" | 停 logger → 按段汇总 | 松手 |

结果：张开 `ct=0`；闭合无振动 `ct=0`；100%/80%/65%/60%/55% **全部 `ct=1`**（判据有滞回）。

## 易错点

1. **模块复位时必须处于张开(START)姿态**，否则 `ang` 恒 0、`closed=0`、`ct` 永远 0（今天踩过）。
2. **等待点是"语音播报"本身**，不要用固定时间表当等待点，也不要让人按回车。
3. 采集进程占着 COM9；测试期间别人不要同时开该串口。
4. 每步都要**当场报数**，不要等整轮跑完才说。
5. 脚本写完的汇总要按**数据特征**（A/F 档位）分段，别依赖 marker 时序——marker 写在段末会错位一格。
