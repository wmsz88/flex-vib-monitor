# 柔性振动检测模块 · 进度与决策

> **开始日期**：2026-10-28　**固件**：`vibmon_v4`（`CT_MODE=3`）　**退路**：`vibmon_v3`（`CT_MODE=2`）
> **装贴**：模块贴**中指指甲盖**，**手指背放**，**初始松手、位置随意**
> **验收口径**：状态只有三个 —— **松手 / 握紧无物 / 接触**。有/无振动是测试时能否分开三态的一个物理条件，不是并列的第四个状态。

---

## 0. 目标：三态 + 两频率

### 0.1 三个验收状态

| 状态 | 操作定义 | 期望外观 | 当前观测量 |
|:--:|---|---|---|
| **松手** | 中指自然舒展背放，模块不碰任何物体 | `D` 小（≈0） | `flatDist` 小 |
| **握紧无物** | 手指合拢用力，**关节转角与真夹住时相同**，但指甲没碰到任何物体 | `D` 大，且**不是接触** | `D` 大；与「接触」的区分待验 |
| **接触** | 指甲压住目标物/振源 | `D` 大，且**判断为接触** | `D` 大；与「握紧无物」的区分待验 |

任意时刻**有且只有一个状态成立**。相邻两态能不能分开是核心验收项：

- **松手 vs 握紧无物**：靠 `D`（姿态门），探针显示余量极大 → 预期可靠。
- **握紧无物 vs 接触**：`D` 几乎相同，**只能靠"有没有物体把振动传过来"** → 本轮头号待验。

### 0.2 振动一档只用于测量，不进验收状态

振源开/关（`V1/V0`）是**测三态时的两种工况**。三态都要在"振源关"和"振源开"下各测一遍，
因为同一个物理状态在这两种工况下出现的行为不同：

| 工况 | 对三态的意义 |
|---|---|
| 振源关 | 松手/握紧无物/接触三态在有无耦合之外的纯姿态差异；接触时若没有振动，能在多大程度上识别它 |
| 振源开 | 振源旁边但没压住 vs 压住同一物体；测"握紧无物"和"接触"能否靠传导差异区分 |

这六种组合就是 §1 的 C1~C6 测量格。**组合不是验收状态**，只是证据集。

### 0.3 另外两个数值读数

| 输出 | 范围 | 来源 | 要出数的时机 |
|---|---|---|---|
| **振动频率** | 80~180 Hz | `Result.freqHz`（`#SWEEP` 的 `F`） | 任何"手上真实接到振动"的时刻（工况 V1 且接触/被传导） |
| **启停频率** | 0~3 Hz | `Result.ssHz`（振/停的节奏，与 `F` 独立） | 专门做振/停节奏子实验（§3.3） |

`?`（无效）≠ `0`：没测出来就写 `?`，不许写成 0。

### 0.4 先读：当前 `ct` 一位表达不了"接触"（主机探针已证实）

用 v4 真实 `state.cpp` + `dsp.cpp` 链到主机测试桩做**每格冷启动**探针
（各自重采松手基准，排除状态串扰）。占位阈值 `D 400/280`、`A 30/20`、`F 120/90`，`DEGRADE_STRICT=0`。

| 格 | 工况 | `D` | `A` | `F` | `cond D/A/F` | `ct` | `grip` | 期望 `ct` |
|:--:|---|--:|--:|--:|:--:|:--:|:--:|:--:|
| C1 G0+V0 | 松手、静止 | 0.0 | 0.00 | 无效 | 0/0/0 | 0 | 0 | 0 |
| C2 G0+V1 | 松手、140Hz 传到 | 0.6 | 81.9 | 140.1 | 0/1/1 | 0 | 0 | 0 |
| C3 G1+V0 | 握紧无物、静止 | 756.1 | 0.00 | 无效 | 1/0/0 | 0 | 1 | 0 |
| **C4 G1+V1** | **握紧无物、140Hz 传到** | 755.5 | 81.9 | 140.1 | 1/1/1 | **1** | 0 | **0** |
| **C5 G2+V0** | **接触、静止** | 756.1 | 0.00 | 无效 | 1/0/0 | **0** | 1 | **1** |
| C6 G2+V1 | 接触、140Hz | 755.5 | 81.9 | 140.1 | 1/1/1 | 1 | 0 | 1 |

**结论一：两个观察轴各自都测得准。** `condPosture` 全部 6 格干净分开
松手（`D` 0.0~0.6）与握紧/接触（`D`≈756），余量两个数量级；`condAmp` / `condFreq`
干净分开有没有振动。**测试要的原始数据是齐的，缺的是把它们组成三态输出的那一步。**

**结论二：真实缺陷是「首次接触必须恰好踩在振动上」**（转移序列探针，不是静态推断）：

| 序列步 | 输入 | `ct` | 真值 |
|---|---|:--:|:--:|
| 手放到静止物体上 | D=756 A=0 F 无效 | **0** | 1 |
| 振源开 | D=756 A=82 F=140 | 1 | 1 |
| 振源关（仍接触） | D=756 A=0 F 无效 | **1** | 1 |
| 松手离开 | D=0 A=0 F 无效 | 0 | 0 |

我上一轮写的"每次停振都掉线"**已撤回**：一旦某次振动建立 `ct=1`，之后停振靠保持规则
（`姿态 && (幅值 || 频率)`，`freqValid=false` 在宽松降级下视为满足）锁住不回零。
真正的失败只有一处：**手在静止物体上首次按下时不报接触**，要等第一次振动才亮。

**结论三：`C3` 与 `C5` 的输入/输出逐位相同** ⇒
「握紧无物 + 静止」与「接触 + 静止」在纯加速度计上**物理不可分**。
这不是 v4 的 bug，是观测量上限。区分它们只能靠"有振动时有没有物体把振动传过来"
（对比 C4 与 C6 的 `A`/`F`）。**而 C4 当前会误判成接触，正是需要实测判定的一件事。**

**本轮实测要回答的关键问题**：

> 振源开着、指甲没压住物体时（C4），`A`/`F` 到底有没有值？

- **几乎为 0 / `F` 无效** ⇒ 握紧无物时振动根本传不到指甲 ⇒ C3 与 C5 仍不可分，**但** C4 与 C6 可分，
  G1/G2 只需要在振动工况下看是否出数。
- **和 C6 一样大** ⇒ 空夹也能传出振动 ⇒ 连"有振动时"也分不开 G1/G2 ⇒ 只能靠 `D` 分
  松手 vs (G1∪G2)，三态塌成两态，走 §4.2 的 M/M3 或退 v3。

## 1. 测量集：三状态 × 两工况 = 六格

状态三个，工况两档（振动关/开），交叉出六格。**六格是证据集，不是验收状态。**

### 1.1 三状态的物理操作

| 状态 | 档号 | 操作定义 |
|:--:|:--:|---|
| **松手** | G0 | 中指自然舒展背放，指甲上模块不碰任何东西 |
| **握紧无物** | G1 | 手指合拢用力（**关节转角与真夹住时相同**），指甲没压到任何物体 |
| **接触** | G2 | 指甲压住目标物/振源 |

### 1.2 两工况

| 工况 | 档号 | 操作 |
|:--:|:--:|---|
| 振动关 | V0 | 振源关闭 |
| 振动开 | V1 | 振源开启，频点取 §2 测定的实际工作频点 |

### 1.3 六格表

| 格 | 状态 + 工况 | 物理含义 | 期望 `ct` | `D` 期望 | 备注 |
|:--:|---|---|:--:|:--:|---|
| C1 | 松手 + V0 | 纯粹静止，无任何耦合 | 0 | 小 | |
| C2 | 松手 + V1 | 振源在旁边/桌面上，指甲没接 | 0 | 小 | 若 `A`/`F` 有值，说明空气/桌面传导 |
| C3 | 握紧无物 + V0 | 指夹空 + 无振动 | 0 | 大 | `grip` 应为 1 |
| **C4** | **握紧无物 + V1** | 指夹空 + 振源开着 | **0（待验）** | 大 | **核心判据**：看 `A`/`F` 有无值 |
| **C5** | 接触 + V0 | 压住静止物体 | 1（当前会漏） | 大 | 当前 `ct=0`，见 §0.4 |
| C6 | 接触 + V1 | 压住振动物体 | 1 | 大 | |

> **C4 vs C6 是唯一可能分开"握紧无物"与"接触"的格对。**
> 若 C4 的 `A`/`F` 几乎为 0、C6 明显有值 → 分开；
> 若两者都有值且量级相同 → 分不开，走 §4。

## 2. 先决条件：确定振源频率范围（P0）

### 2.1 为什么先测振源

振动频率读数需要参考真值才能算 ±2Hz；同时 C4 是否有 `A`/`F`、与 C6 差多少，
依赖振源实际频点（占位 `CT_FLAT_F_ON_HZ=120` 只是猜测）。

### 2.2 P0 测量表（刚性耦合，不上手指）

| 振源设定 | 可调? | `F` 中位 Hz | `F` 有效% | `A` 中位 mg | `ax` | 备注 |
|---|---|---|---|---|---|---|
| 最低档 | | | | | | 实际下限 |
| 中段 | | | | | | |
| 最高档 | | | | | | 实际上限 |
| 关闭 | | | | | | **应为 `?`**，仍出数=有串扰 |

**P0 存档三句话**：振源可用频带 ___~___ Hz；本次工作频点 ___ Hz；
关源时 `F` 有效率 ___%（应≈0）。

### 2.3 口径

| 项 | 性质 |
|---|---|
| 持续振动 80~180 Hz、启停 0~3 Hz | **命题要求** |
| 误差 ≤±2Hz、延迟 ≤0.5s | **本组工程目标，不是官方考核标准** |
| 算法可测带 60~220 Hz / 0.083~5 Hz | 内部容错，对外不承诺 |

### 2.4 振源接口（2026-10-29 实测确认）

振源是独立板 `vibsource`（ESP32-C3 SuperMini + ERM 电机），**在 COM7**，
115200 8N1。上电横幅与 `q` 查询已实测：

| 命令 | 作用 |
|:--:|---|
| `0`~`9` | 占空比 = 数字 × 10%（`9`=90%，`0`=停止） |
| `h` | 100% |
| `p` | 跳到 **55%（标称约 80Hz 工作点）** |
| `+` / `-` | 占空比 ±5% |
| `s` | 自动降档扫频 100%→55%，每档 3s |
| `x` | 停止扫频 |
| `T0`/`T1`/`T2`/`T3` | 自动通断 **0.5 / 1 / 2 / 3 Hz**（测启停频率用） |
| `T` | 停止通断 |
| `z` | 停止（占空比 0） |
| `q` | 查询状态 |

**两个必须注意的物理限制**

1. **振源只能设占空比，不能直接设频率。** 频率是 ERM 转速的结果（单调但非线性），
   所以 P3 **不能"命令 80/100/130/160/180Hz"**，只能"扫占空比 → 记录实测频率"，
   再检验映射的**重复性**（同一占空比两次跑是否落在 ±2Hz 内）。
   真正可用的验收写法：**同一占空比重复 3 次，测得频率极差 ≤4Hz**。
2. **55% 低于启动门槛（约 74%）**，靠"踢一脚"启动。低占空比时电机可能根本不转，
   表现为 `A`/`F` 突然掉到噪声 —— **别误判成"接触丢了"**。
   每次降档后要用 `q` 确认电机确实在转，或在采集里加一段 `h` 再回落。

## 3. 测量矩阵与流程

### 3.1 采集命令：**一格一个文件**

态号里 `0` 同时对应 C1/C2、`4` 同时对应 C3/C4，**脚本分不出振源开没开**。
所以**一格跑一次、文件名带格号**，别把六格串在一条 `--steps` 里：

```powershell
# C1 松手 + 振源关
python -X utf8 _probe\capture_measure.py --port COM5 --mode sweep `
    --steps 0:60 --out data\C1_O1
# C2 松手 + 振源开
python -X utf8 _probe\capture_measure.py --port COM5 --mode sweep `
    --steps 0:60 --out data\C2_O1
# C3 握紧无物 + 振源关
python -X utf8 _probe\capture_measure.py --port COM5 --mode sweep `
    --steps 4:60 --out data\C3_O1
# C4 握紧无物 + 振源开   <- 决定生死的一格
python -X utf8 _probe\capture_measure.py --port COM5 --mode sweep `
    --steps 4:60 --out data\C4_O1
# C5 接触 + 振源关
python -X utf8 _probe\capture_measure.py --port COM5 --mode sweep `
    --steps 1:60 --out data\C5_O1
# C6 接触 + 振源开
python -X utf8 _probe\capture_measure.py --port COM5 --mode sweep `
    --steps 6:60 --out data\C6_O1
```

文件名约定 `<格号>_<朝向>`（`O1/O2/O3`），换朝向时**重按 `t` 采松手基准**。
`--steps` 的态号只用于让脚本打标签，**真正的分类靠 CSV 里的 `D / A / F / vib` 逐列还原**。

> 想省事也可以一条命令跑 `--steps 0:60,6:60`（松手→接触），但 C3 与 C4 必须分文件，
> 否则事后无法区分"振源关着的空夹"和"振源开着的空夹"。

### 3.2 六格数据表（每个松手朝向都要跑一遍）

朝向定义：松手时中指指甲法线方向，至少 O1 朝上 / O2 侧向 / O3 朝下。

| 格 | 朝向 | `D` min/med/max | `A` min/med/max | `F` min/med/max | `F` 有效% | `vib` | `ct` | `grip` |
|:--:|:--:|---|---|---|---|:--:|:--:|:--:|
| C1 松手+V0 | O1 | | | | | | | |
| C2 松手+V1 | O1 | | | | | | | |
| C3 握紧无物+V0 | O1 | | | | | | | |
| **C4 握紧无物+V1** | O1 | | | | | | | |
| **C5 接触+V0** | O1 | | | | | | | |
| C6 接触+V1 | O1 | | | | | | | |
| … | O2/O3 | 换朝向重复 6 行 | | | | | | |

**每格操作纪律**（照错会产生假数据）：

| 格 | 必须做到 | 常见做错 |
|:--:|---|---|
| C1 | 手完全放松，指甲不碰任何东西 | 手指绷紧 → `D` 偏大 |
| C2 | 振源开但隔空/放桌面，指甲不接 | 无意碰到 → 变 C6 |
| C3 | 转角与真夹住一致，只差没有物体 | 只合一点 → `D` 不够大 |
| C4 | 振源开 + 同 C3（**关源就白测**） | 手抖碰到振源 |
| C5 | 指甲确实压住静止物体 | 物体有余振 → 变 C6 |
| C6 | 指甲压住振源 | 绑带旁路传导 |

### 3.3 启停频率（接触态下做）

| 设定 SS (Hz) | 测得中位 Hz | 首次出数 s | 停后是否立即失效 |
|---|---|---|---|
| 0.1 / 0.25 / 0.5 / 1.0 / 2.0 / 3.0 | | | |

占空比至少两组（1:1 与 1:2）。

### 3.4 振动频率精度

在 C6（或 C2）下逐频点测：振源实际点 / 80 / 100 / 130 / 160 / 180，每点 ≥30s，
记中位数、误差、≤±2Hz、`ax`、`cliplim`。

### 3.5 每次开机必查

- `S` 显示 `接触 0(可信)  平放到 N mg`（基准没采到，后面全废）
- `T`：读耗时 <500us、样本间隔 ≈1000us、缓冲 <50%、削顶 0
- `#SWEEP` 的 `tr`（基准极差）< 60 mg

## 4. 判据现状与出路

### 4.1 现在到底能分开什么

| 区分 | 依据 | 现状 |
|---|---|---|
| 松手 vs 握紧无物/接触 | `D` 姿态门 | ✅ 探针可靠，余量两个数量级 |
| 握紧无物 vs 接触（有振动） | C4 与 C6 的 `A`/`F` 差异 | ❓ **完全未验**，靠实测 C4 回答 |
| 握紧无物 vs 接触（无振动） | — | ❌ **物理不可分**（C3≡C5，纯加速度计上限） |

### 4.2 三条出路（测完择一，**均需批准才动代码**）

| # | 做法 | 改动量 | 得到什么 | 代价 |
|:--:|---|---|---|---|
| M1 | `进入 = 姿态`，保持规则不变 | 约 1 行 | 接触轴干净，C5 不再漏 | G1/G2 仍不分，`ct` 变"握紧了" |
| M2 | 拆两个输出：接触轴 + 振动轴，上层交叉 | 中，动帧协议 | 三态完整、物理上限内最优 | 帧字段要重新对齐 |
| M3 | 保留三重与，`F` 阈值改"带内有振"（75/65）+ `DEGRADE_STRICT=1` | 只改宏 | 振动时能进，静止时不漏进 | C5 漏报没解决 |

> **倾向 M2**。既然 G1/V0 与 G2/V0 物理不可分，就不要假装一个 `ct` 位能分；
> 把接触轴（`D`）和振动轴（`vib`/`F`）各自报准，三态由上层交叉。

### 4.3 退 v3 的条件

v3 = `CT_MODE=2`：握住有物体时按 `t` 记接触姿态，判「到接触姿态距离 < 400mg」，
**没有幅值门/频率门**（已核实 `vibmon_v3/state.cpp` 无 `combineContact`/`gripNoObject`）。

| 能力 | v4 | v3 |
|---|:--:|:--:|
| 松手 vs 握紧/接触 | ✅ | ✅（需现场按 `t` 记接触姿态） |
| 握紧无物 vs 接触 | ❓ 押在 C4/C6 | ❌ 本来就分不开 |
| 静止时首次接触 | ❌ 漏报（§0.4 结论二） | ✅ 不漏（只看姿态） |

退路四判据：

| # | 触发 | 结论 |
|:--:|---|---|
| K1 | 某朝向松手 `D` 中位 > `CT_FLAT_D_ON` | 零点不可复现，两版都不能用，先修装贴 |
| K2 | C4 的 `A`/`F` 与 C6 同量级 | G1/G2 靠振动也分不开 ⇒ 三态塌两态 ⇒ M2 或退 v3 |
| K3 | 某朝向握紧 `D` ≈ 松手 `D` | 姿态门失效，与"位置随意"冲突 |
| K4 | G2 态 `F` 有效率 <70% | 测频失败，先修耦合再谈判据 |

## 8. 实测记录 2026-10-29（真实硬件）

**硬件**：检测模块 COM8（vibmon_v4，`CT_MODE=3`，贴机械手中指指甲盖、手指背放）；振源 COM7（vibsource ERM）。
**方法**：`w` 命令 1Hz 采样，每格 30s；`_probe/capture_measure.py` 落 CSV，原始行在同名 `.raw.txt`。

### 8.1 六格实测

| 格 | 工况 | `D` 中位 | `A` 中位 | `F` | `ct` | 判定 |
|:--:|---|---:|---:|---|---|---|
| C1 | 松手 + 振源关 | **1 mg** | 6.0 mg | 全部无效 | 0/29 | ✅ 正确 |
| C3 | 握紧无物 + 振源关 | **1853 mg** | 6.1 mg | 全部无效 | **1/29** | ❌ 误报 |
| C5 | 接触 + 振源关（换位置后） | 25 mg | 6.0 mg | 全部无效 | 0/29 | ❌ 漏报 |
| C5b | 接触 + 振源关（同位置重采基准） | **6 mg** | 6.0 mg | 全部无效 | 0/29 | ❌ 漏报 |
| C4 | 握紧无物 + 振源开 | 551 mg | **6.4 mg** | **全部无效** | **1/29** | ❌ 误报 |
| C6 | 接触 + 振源开（**马达确认在转**） | **1749 mg** | **754.9 mg** | **172.8 Hz**（27/27 有效） | **1/27** | ✅ 正确 |
| 联动 | 指甲压住 100% 电机 | — | **258.8 mg** | **178.6 Hz** | — | 强耦合 |

### 8.2 四条结论

1. **空夹不传振动（关键）**：马达 100% 转时，压住的指甲测得 `A`=258.8mg / `F`=178.6Hz，
   而空夹只有 `A`=6.4mg / `F` 全无效。**差 40 倍，振动轴能分开"接触"与"握紧无物"。**
2. **`D` 跟的是位置，不是动作**：同样是"闭合"，C3 得到 1853mg、C5b 得到 6mg。
   `D` 衡量的是"模块相对采基准那一刻转了多少"，机械手整体换位置就失真。
   ⇒ 必须在**同一位置**先采基准再动作，`D` 才有意义。
3. **`ct` 不可用**：C3/C4 的 `ct=1` 是闭合动作的瞬态点着后靠宽松降级锁住的；
   C5/C5b 明明接触却 `ct=0`（`D` 没过 400）。`ct` 实际等价于"`D`>400 且曾被瞬态触发"。
4. **模块会自行重标定**：期间出现多次 `[CAL] 本次：成功`，阈值在 15.8/14.3 间变化，
   `|g|` 一度到 1105mg、`std` 14.5mg ⇒ **标定时机械手在动**，标定值不可信，基准被连带清掉
   （C5b 有 9/29 行 `D` 无效即此故）。

### 8.3 对判据的直接含义

- 三态里的 **松手 vs 非松手**：`D` 可用，但**必须同位置采基准**。
- **接触 vs 握紧无物**：靠 `A`/`F`，前提是目标物在振（实测差 40 倍，可用）。
- **接触 vs 握紧无物（目标物不振）**：仍物理不可分（C5b 与 C3 的差别只是位置）。
- `ct` 这个单一位建议按 §4.2 的 **M2** 拆成两轴，否则无法同时满足"接触要报 1"和"空夹要报 0"。

### 8.5 判据修正建议（基于实测，未改代码）

把五格摆在一起，**两轴其实都工作得很好，坏的是把它们 AND 进一个 `ct` 的方式**：

| 格 | `D` | `A` | `F` | 应当 |
|---|---:|---:|---|---|
| C1 松手 + 关 | 1 | 6.0 | 无效 | 非接触 |
| C3 握紧无物 + 关 | 1853 | 6.1 | 无效 | 非接触 |
| C4 握紧无物 + 开 | 551 | **6.4** | **无效** | 非接触 |
| C6 接触 + 开 | 1749 | **754.9** | **172.8** | **接触** |
| C5b 接触 + 关 | 6 | 6.0 | 无效 | 接触（物理不可分，见 §8.3） |

**建议试 `CT_FLAT_DEGRADE_STRICT=1`（只改编译宏，不动源码）**，理由：

- 现在 `=0` 时"数据失效视为满足"，导致 C3/C4 靠瞬态点着后锁死 → 误报。
- 改成 `=1` 后：`freqValid=false` 一律视为不满足 ⇒ 没有振动就进不了也保持不了接触。
- 按实测值推演（`A_ON=30`、`F_ON=120`）：
  - C1 `A`=6.0、`F` 无效 → 0 ✅
  - C3 `A`=6.1、`F` 无效 → 0 ✅（修掉误报）
  - C4 `A`=6.4、`F` 无效 → 0 ✅（修掉误报）
  - C6 `A`=755、`F`=172.8 → 1 ✅
  - C5b `A`=6.0、`F` 无效 → **0（仍漏报）**，这是"物体不振时物理不可分"的必然结果

**代价**：接触判定变成"必须正在振"。若比赛里目标物一直振，这正好；若要支持"接触但物体停振"，必须走 §4.2 的 M2（拆两轴输出）。

**验证方式**（不改源码，只加编译宏）：

```powershell
arduino-cli compile -b esp32:esp32:esp32c3 `
  --build-property "compiler.cpp.extra_flags=-DCT_FLAT_DEGRADE_STRICT=1" vibmon_v4
```
然后重跑 C3 / C4 / C6 三格即可判定。

### 8.7 「收缩程度」实验（2026-10-29，三轮：平放→夹空气→平放→夹物体）

**目的**：验证能否用 `D`（姿态变化）区分"夹空气"与"夹住物体"，即"收缩程度"是否可观测。
**方法**：每段平放末尾自动按 `t` 重采基准，随后闭合 22s；振源全程关闭。
**数据**：`data/R3b.csv`，188 行（已剔除每段前 3 个瞬态采样）。

| 段 | `D` 中位 | `D` 范围 | 与"夹空气"之差 |
|---|---:|---|---:|
| R1 夹空气 | **1751** | 616~1754 | — |
| R1 夹物体 #1（薄） | **1712** | 418~1716 | **−39 mg（2.2%）** |
| R2 夹空气 | **1727** | 431~1754 | — |
| R2 夹物体 #2（中） | **1691** | 409~1692 | **−36 mg（2.1%）** |
| R3 夹空气 | **1750** | 397~1751 | — |
| R3 夹物体 #3（厚） | **1578** | **1577~1580** | **−172 mg（9.8%）** |

**三条结论**

1. **收缩程度确实可观测，但很弱**：厚物体只让 `D` 下降 ~10%，薄/中厚物体只有 ~2%。
2. **重复性很好**：三次夹空气 1751 / 1727 / 1750（极差 24mg，1.4%）；厚物体那一段
   `D` 稳定在 1577~1580（极差 3mg）。**所以 10% 的差异是真实的，不是噪声。**
3. **薄物体分不开**：2% 的差异与"夹空气"自身的 1.4% 波动同量级，
   靠 `D` 判"夹没夹到薄物体"不可行。

**顺带暴露的问题**：三段"平放"的 `D` 分别是 246 / 293 / 1578，而理想应为 0。
说明**机械手回位不一致**（张开姿态没有机械限位），这是 `D` 判据当前最大的噪声源，
比传感器噪声大两个数量级。要稳定用 `D`，先解决"张开姿态可重复"。

**对判据的含义**

| 场景 | `D` 能否判"夹住" |
|---|---|
| 物体厚度 >= 约 8~10mm（本次 #3） | 可行，窗口约 1650 可分（1578 vs 1750） |
| 物体较薄 | 不可行，需陀螺仪积分角度 |
| 回位不重复 | 先做机械限位 |
